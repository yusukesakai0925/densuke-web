収録範囲・仕組み

「売買の契約不適合を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法の本則のうち、第562条〜第568条・第572条をルールにしています。

入力の欄は、起きた事実を聞く19個で、いつも全部を出します。同じ入力で第562条〜第568条・第572条を全部当てるので、例えば「品質の違う物を受け取り、その後どちらのせいでもなく、なくなった」を選ぶと、第562条・第563条と第567条の両方の判定が出ます。前の欄の答えで意味を持たない欄（例：契約の内容どおりなのに選んだ催告の欄）は、答えに使いません。事実として成り立たない組は「この組み合わせはありません」と、欄の番号と根拠条を出します。裁判所などでどうなるかを当てる道具ではなく、入力のとおりなら条文がどう定めているかを確かめるものです。個別のことは法律の専門家に聞いてください。

入っていないもの：下の載せなかったものをご覧ください。損害賠償（第415条）と解除（第541条・第542条）に当たるか、権利が時効で消えるかは、このページでは扱いません。

判定について：

  • 当てはめは判定しません。「契約の内容に適合しない」「不相当な負担」「相当の期間」「買主の責めに帰すべき事由」「重大な過失」「無資力」「売買の目的として特定したもの」「当事者双方の責めに帰することができない事由」に当たるかは、事情で決まり、条文だけでは決まりません。本人がそう考えているかを入力にしているだけです。不適合が買主と売主の両方の事由によるときに「買主の責めに帰すべき事由によるもの」に当たるかも、条文だけでは決まりません。代金をいくら減らせるかは計算しません。
  • 条文だけを読んでいます。判例の読み方は載せません。
  • 損害賠償（第415条）と解除（第541条・第542条）は第564条・第568条の引き先で、中身は読んでいません。当たるか、権利が時効で消えるかは、このページでは扱いません。
  • 重なりは並べて出します。同じ入力で2つ以上の条が当たるとき（例：品質の違う物を受け取った後に、どちらのせいでもなく、なくなった）は、どちらの判定も出します。どちらが優先するかの語は条文に無いので、出しません。ただし、1年以内に知らせなかったことで請求も解除もできなくなったとき（第566条本文）は、第562条〜第564条・第572条の答えを出しません。担保の責任を負わない特約をして、第572条の免れることができない場合に当たらないときも、第562条〜第564条の答えを出しません。競売で買ったときは、第568条で答え、売主との売買の定め（第562条〜第567条・第572条）は答えに使いません。
  • 語の言い換え：履行の追完＝直すこと（修補）、代わりの物を渡すこと、足りない分を渡すこと。催告＝期間を決めて、直すよう求めること。不相当な負担＝買主に釣り合わない負担。買主の責めに帰すべき事由＝買主のせい。引渡し・履行の提供＝物を渡すこと・渡そうとすること。滅失・損傷＝なくなること・壊れること。売買の目的として特定したもの＝売買で「この物」と決めた物。当事者双方の責めに帰することができない事由＝売主のせいでも買主のせいでもないこと。買受人＝競売で買った人。債務者＝競売にかけられた物の持ち主。無資力＝お金が足りず払えない状態。担保の責任を負わない旨の特約＝売主が責任を負わない約束。これらは条文の語をこのアプリが言い換えたものです。
民法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（民法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは「当たりません」とだけ出し、反対の結論（ほかの理由で請求できる・責任を負わない等）は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例の基準：条文だけを読むアプリのため
  • 減額の金額の計算：条文は「その不適合の程度に応じて」までで、計算の語が無いため
  • 第415条・第541条・第542条の中身：第564条・第568条の引き先のため。引き先の判定は債務不履行と解除のページへのリンクだけを置く
  • 第559条（売買以外の有償契約への準用）：売買の話に絞るため
  • 第569〜571条・第573条以下：今回の問いの外のため
  • 消費者契約法との関係：別の法律のため
  • 商人間の売買の特則（商法）：別の法律のため
  • 契約の内容の解釈：何が契約の内容かは本人の入力として受けるため

条文だけで決まらなかった点（24点）：

  • （a）572条は「免れることができない」場合だけを書き、それ以外で特約が有効かは書いていない → 当たらないときは「当たりません」とだけ出し、特約の効力そのものは出さない。特約が効くかを言わないので、そのときは562条〜564条の「請求することができます」などの答えも出さない
  • （b）引渡しの前から不適合があった目的物が、引渡しの後に双方の責めなく滅失又は損傷したとき、567条1項が元の不適合を理由とする請求まで止めるか → 562条・563条の答えと、567条1項の「滅失（損傷）を理由として」請求できない答えを並べ、どちらが優先するかは出さない
  • （c）不適合が買主と売主の両方の事由によるときに「買主の責めに帰すべき事由によるもの」に当たるか → 入力は「買主のせいである／ではない」の2択のままにして、決まらない旨を「判定について」に書く
  • （d）565条で準用するときの「目的物の修補、代替物の引渡し又は不足分の引渡し」を、権利についてどう読むか → 語が無いので、権利の入力では方法を並べず「履行の追完」とだけ出す
  • （e）567条1項の「以下この条において同じ」 → 2項の目的物も特定したものに限ると読み、特定していない入力では2項にも当たらないと出す
  • （f）563条1項の催告をして期間内に履行の追完があったのに、2項の号の欄も選んだとき → 2項に履行の追完があった場合の語が無いので、号の欄は答えに使わず、1項に当たらないと出す
  • （g）563条1項の催告をして期間内に履行の追完がなく、2項の号にも当たるとき → どちらの根拠も並べ、「催告をすることなく」の答えを出す
  • （h）563条2項4号の「前三号に掲げる場合のほか」 → 1〜3号のどれかに当たるときは、4号の欄は答えに使わない
  • （i）566条と567条の両方に当たるとき → 順番の語が無いので、別の段で並べる
  • （j）562条1項本文の「引き渡された目的物」と566条の「引き渡した場合」 → 物の不適合は、2の欄で「渡した」のときだけ562条〜564条・566条・572条を当てる。まだ渡していないときは「引き渡された目的物」に当たらないと出す。移転した権利は2の欄を問わない
  • （k）566条の「知った時から一年以内」で、まだ知らない・まだ一年を過ぎていないとき → 欄は「知らせた／知らせなかった」で、知った時と経過は聞かない
  • （l）567条2項の「契約の内容に適合する目的物をもって…提供した」と1の欄 → 物の種類・品質・数量が合っていないのに「合う物で渡そうとした」、合っているのに「合わない物で渡そうとした」を選んだときは、この組み合わせはありませんと出す
  • （m）567条2項の「前項と同様」に1項の2文目（代金の支払）も入るか → 1項の2文とも同様と読み、代金の段も出す
  • （n）568条1項の引き先（第541条・第542条・第563条）の要件 → 聞かず、「規定により」の語を落とさずに出す
  • （o）568条2項の「前項の場合」・3項の「前二項の場合」 → 1項で解除・減額を請求できるとき（数量・移転した権利）だけ、2項・3項の答えを出す
  • （p）568条3項で債務者も債権者も当たるとき → 分担の語が無いので、「これらの者に対し」を「債務者と債権者に対し」と書く
  • （q）種類・品質・数量・権利のうち複数の不適合が重なるとき → 語が無いので、どれか1つを選ぶ欄にした
  • （r）568条と572条の関係 → 語が無いので、別の段で並べるだけにした
  • （s）572条の「知りながら告げなかった事実」と不適合の関係 → その事実が不適合に関わるかは聞かず、本人の入力として受ける
  • （t）564条と、買主の責めに帰すべき事由による不適合 → 564条に除く語が無いので、その入力でも「妨げません」を出す。564条は定めを述べるだけなので、結論の箱には入れず、番号つきの節と論理の木に出す
  • （u）562条1項ただし書で買主がどの方法を請求したか → 修補・代替物の引渡し・不足分の引渡しのどれかは聞かず、「違うやり方か」だけを聞く
  • （v）566条本文で、買主が履行の追完の請求・代金の減額の請求・損害賠償の請求・契約の解除をすることができなくなったとき → 562条〜564条・572条の答えは出さない（「請求することができます」と並べると矛盾に読める）
  • （w）競売で買ったとき → 568条1項が買受人の解除・減額を定めるので568条で答え、売主との売買の定め（562条〜567条・572条）は答えに使わない
  • （x）前の欄の答えで意味を持たない欄 → 答えに使わない（例：契約の内容どおりなのに選んだ催告の欄、競売でないのに選んだ持ち主の欄）。事実として成り立たない組（1と3、1と10、1と2、2と11の欄）は、この組み合わせはありませんと根拠条つきで出す
