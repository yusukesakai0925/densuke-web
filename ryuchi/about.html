収録範囲・仕組み

「留置権と質権を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法の本則のうち、第295条〜第302条、第342条〜第351条と、第350条で準用する第304条第1項をルールにしています。

物の占有と担保の約束について起きた事実の21個の欄から、第295条〜第302条・第342条〜第351条を同じ入力で全部当てます。どの条の話かを先に選ぶ欄は置いていません。

入っていないもの：下の載せなかったものをご覧ください。抵当権は抵当権のページで、保証の求償は保証のページで、不法行為は不法行為のページで引いてください。

判定について：

  • 当てはめは判定しません。物に関して生じた債権か、占有が不法行為によって始まったか、善良な管理者の注意をもって占有しているか、物の保存に必要な使用か、必要費・有益費の別、価格の増加が現存するか、相当の担保か、譲り渡すことができない物か、別段の定めがあるか、優先権を有する債権者か、不可抗力によるものかは、裁判所が決める評価です。本人の答えを入力にしているだけです。
  • 条文だけを読んでいます。判例は載せません。弁済期と質権の存続期間の数え方は条文に書いていないので、本人の答えで受けています。
  • 別の法律は読んでいません。商法の留置権・質権、民事執行法の手続、経過措置（附則）は載せません。
  • 関係のない欄（たとえば、1の欄が「他人の物を占有している（担保とする約束はない）」のときの2・7〜9・17〜21の欄）は、答えを出さないだけで、「この組み合わせはありません」にはしません。「この組み合わせはありません」になるのは、11と18の欄の1組だけです。
民法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（民法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは、欠けた要件が分かる起きた事実の文だけを出し、反対の結論は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例の基準（牽連性、第三者への主張、転質の種類など）：条文だけを読むアプリのため
  • 商法の留置権・質権：別の法律のため
  • 先取特権（第303条〜第341条）：別の担保物権で条の数が多いため。第304条は第350条の準用の語だけ扱う
  • 第304条第2項（債務者が設定した物権の対価）：聞く欄を置いていないため（下の（m））
  • 不動産質・権利質（第352条〜第366条）：動産の質権と留置権の範囲の外のため
  • 質権の消滅時効・流質の例外など他法の定め：民法のこの範囲の条文にないため
  • 金額の計算：条文は「支出した金額又は増価額」までのため
  • 民事執行法の手続：別の法律のため

条文だけで決まらなかった点（22点）：

  • （a）295条1項の「他人の物」の「他人」が債務者に限られるかは書いていない → 語のとおり聞く。これは読みです
  • （b）298条3項の「前二項の規定に違反した」の中身と程度は書いていない → 11の欄で保存に必要でない使用・賃貸・質権の目的とした・それ以外の担保に供したことを12の欄で債務者の承諾を得ずにしたときを298条2項の違反、13の欄で善良な管理者の注意をもって占有していないときを298条1項の違反として、298条3項の答えを出す。違反の程度や結果は聞かない。これは読みです
  • （c）302条ただし書の「第二百九十八条第二項の規定により」 → 12の欄で債務者の承諾を得て賃貸し、又は質権の目的としたと読む。承諾を得ずに賃貸し、又は質権の目的として占有を失ったときは、302条本文（留置権は消滅します）と298条3項（消滅を請求することができます）の両方を出す。302条本文で留置権が消滅したときは、留置を続ける前提の295条・296条・297条・298条1項・299条・300条・301条の答えを出さない。これは読みです
  • （d）350条は読み替えを書いていない → 留置権者を質権者、留置物を質物、留置権を質権と読み替えた文で答え、根拠に350条と準用する条を並べる。これは読みです
  • （e）347条ただし書の「優先権を有する債権者」が誰かは書いていない → 9の欄で物を引き渡すよう求めている人を聞き、優先権を有する債権者かは本人の答えで受ける。これは読みです
  • （f）295条1項本文・295条1項ただし書・295条2項の要件が2つ以上欠けたときの先後は書いていない → 欠けた要件を全部並べ、占有者は物を留置することができないと答える。これは条文の裏の読みです
  • （g）344条は引き渡していないときの語を書いていない → 「引き渡すことによって」生ずるという語から「効力を生じません」と答える。引渡しを受けていないときと、譲り渡すことができない物のときは、342条・345条〜351条の答えを出さない。これは読みです
  • （h）345条は質権設定者に占有させたときの結果を書いていない → 「させることができません」とだけ答え、設定の効力や質権の消滅は言わない。これは読みです
  • （i）300条の「留置権の行使」に物を留置していることが入るかは語だけで言い切れない → 留置権が成り立つとき（質権では効力を生じるとき）にいつも答える。298条1項も同じくいつも答える。これは読みです
  • （j）348条前段は「存続期間内において」転質をすることができると書き、後段は「この場合において」「不可抗力によるものであっても」と書く → 存続期間の外では転質をすることができないと答え（これは条文の裏の読みです）、後段は前段で転質をすることができるときだけ答える。不可抗力によるものでない損失も責任を負うと読む。これは読みです
  • （k）348条（質権者は転質をすることができる）と、350条で準用する298条2項（債務者の承諾を得なければ担保に供することができない）の関係は書いていない → 11の欄で質権の目的としたときは348条を転質の定めとして先に当て、350条で準用する298条2項の答えは出さない。使用・賃貸・それ以外の担保に供したときだけ298条2項を準用して答える。これは読みです
  • （l）350条が準用する298条の「債務者」は、質権設定者が第三者のときに読み替えるかが書いていない → 語のまま「債務者」と出す。これは読みです
  • （m）350条が準用する304条・298条3項・300条には「留置権者」「留置物」以外の語がある → 「先取特権」「留置権」を質権、「先取特権者」を質権者、「目的物」を質物と読む。304条2項（債務者が設定した物権の対価）は聞く欄を置かない。これは読みです
  • （n）295条1項本文と347条本文の「弁済を受けるまで」は、全部の弁済を受けた後を書いていない → 物を留置することができないと答え、留置権では296条〜302条の答えを出さず、質権では350条で準用する296条・297条・304条の答えを出さない。全部の弁済を受けたときは、347条の答えだけを出す（留置権の 295条と同じ扱い。344条・342条・346条・348条・349条と350条で準用する298条〜300条も出さない。弁済した後の求償の351条は出す）。これは条文の裏の読みです
  • （o）351条の「保証債務に関する規定」がどの条かは書いていない → 条を指さず語のまま出す。これは読みです
  • （p）349条は設定行為と弁済期前の契約しか書かず、弁済期の後の約束を書いていない → 349条が禁じる約束ではないとだけ答え、有効とは言わない。「その他法律に定める方法によらないで質物を処分させること」は聞かない。これは読みです
  • （q）346条本文の6つ以外の債権と、346条ただし書の「別段の定め」の中身は書いていない → 6つのどれでもなく別段の定めも無いときは、質権は債権を担保しないと答える（これは条文の裏の読みです）。別段の定めがあるときは、担保するかは別段の定めによると答える。これは読みです
  • （r）301条は消滅を「請求することができる」と書くが、請求した後いつ消えるかは書いていない → 請求できるとだけ出し、消滅したとは言わない。これは読みです
  • （s）298条2項本文は「債務者の承諾を得なければ」使用し、賃貸し、又は担保に供することができないと書く → 承諾を得たときは、することができると答える。これは条文の裏の読みです
  • （t）299条2項本文は「価格の増加が現存する場合に限り」と書く → 現存しないときは、有益費を償還させることができないと答える。これは条文の裏の読みです
  • （u）350条は301条・302条を準用していない → 質権のとき15・16の欄の答えは出さず、「準用されていません」とも出さない。これは読みです
  • （v）295条1項は「他人の物の占有者」について書き、物を占有していない人を書いていない → 1の欄で物を占有しておらず担保とする約束もないときは、物を留置することができないと答える。これは条文の裏の読みです
