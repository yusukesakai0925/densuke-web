収録範囲・仕組み

「予算と決算の決まりを逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

地方自治法の本則のうち、第97条第2項・第112条・第211条第1項・第212条第1項・第213条第1項・第214条・第217条・第218条第1項〜第3項・第219条・第220条第2項・第3項・第222条第1項・第233条第1項〜第3項・第5項〜第7項・第235条の5・第283条第1項をルールにしています。

収録しているのは「長が予算を作って議会に出し、議会が議決し、議長が長へ送るまで」「議員が出す議案と、議会の増額の議決」「新しく費用のかかる条例案など」「予算のお金を翌年度に使う・何年度かにわたって払う・款や項の間で移す・予備費から出す・将来の支払いを約束する」「会計管理者が決算を出してから、議会の認定と、認定されなかったあとの措置まで」です。

入っていないもの：長の予算の提出の権限を侵すか・予算を執行するのに本当に必要か・本当に避けられない出来事か・予算上の措置の見込みが本当にあるか（このアプリは長がしたことを事実として聞き、条文に中身の無い3つは「あなたの考え」として聞くだけです。下の約束事①）、判例・通達・行政実例、政令（予算の説明書・予算の執行の手続・決算に付ける書類・継続費の逓次繰越しなど）、他の法律。詳しくは載せなかったものをご覧ください。議会の議決に長が異議を示したときの再議は再議・不信任・専決処分のページで引いてください。

判定ページは25個の欄をいつも全部出し、選んだ値によって欄を出したり消したり、欄の名前を変えたりしません。入力に関わらない欄は、判定で見ないだけです。3つの小見出しの答えは、同じ入力で全部出します。

  • 3の欄（年度開始の何日前に出したか）：2の欄が年度の予算でなければ見ません。空なら、日数を聞かずに、年度の予算を作って議決を経ることと、30日・20日の期限だけを出します
  • 4の欄（補正予算に入れた事柄が起きた時）：2の欄が補正予算でなければ見ません。5の欄（暫定予算のあとの年度の予算）：2の欄が暫定予算でなければ見ません
  • 8・9の欄（議長が送った日数・送られた予算を受けた長）：7の欄が「まだ」なら見ません。8の欄が空なら、まだ送っていないとして3日の期限だけを出し、9の欄は見ません
  • 12・13の欄（支出負担行為・終わらなかったわけ）：11の欄が「繰越明許費ではない」でなければ見ません。13の欄は12の欄が「した」のときだけ見ます。14の欄で継続費として定めていれば、翌年度に使えるかの答えを出しません（下の (e)）
  • 16・17の欄（項の間の移し替えの定めとわけ）：15の欄が「同じ款の中の項と項の間で移す」でなければ見ません
  • 19の欄（予備費の計上）：一般会計・特別会計で「計上した」なら、答えを出しません
  • 25の欄（否決のあとの措置）：24の欄が「否決した」でなければ見ません

「この組み合わせはありません」と出すのは6の組です。ア：2の欄が「出していない」で、7の欄が「まだ」以外（211条1項・218条1項・218条2項。議会が議決する予算は、長が作って議会に出すもの）。イ：7の欄が「まだ」で、8の欄に日数がある（219条1項。議長が送るのは、予算を定める議決があったとき）。ウ：18の欄が「出さない」以外で、19の欄が「計上していない」（217条1項。予備費から出すのは、予算に計上した予備費）。エ：21の欄が「出していない」で、22の欄が「付した」（233条2項）。オ：21の欄が「出していない」で、23の欄が「付していない」以外（233条1項・233条3項）。カ：23の欄が「付していない」で、24の欄が「まだ」以外（233条3項。議会が認定を議決するのは、長が認定に付した決算）。2つ以上の組が重なれば、全部出します。

議員が予算の議案を出したとき（第112条第1項ただし書）、長が監査委員の審査に付さずに決算を議会の認定に付したとき（第233条第2項）、一般会計で予備費を計上していないとき（第217条第1項）は、法に反することも起きうる事実なので、「この組み合わせはありません」にせず、「出せません」「先に…付さなければなりません」「計上しなければなりません」と答えます。

否決された決算：第233条第7項は、長が措置をとったときの報告と公表を書くだけです。決算や支出の効力がなくなるとは書いていません。

地方自治法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。使っている条のマスを押すと原文が出ます。

アプリの約束事（地方自治法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • ①第218条第1項「変更を加える必要が生じたとき」・第219条第2項「再議その他の措置を講ずる必要がないと認めるとき」は、要件が長の判断そのものなので、2の欄で長が補正予算を出したこと、9の欄で長が再議にかけずに受け取ったことを、事実として選んでもらう。第220条第2項ただし書「予算の執行上必要がある場合」・第220条第3項ただし書「避けがたい事故のため」・第222条第1項「見込みが得られる」は、条文に中身が無いので判定せず、17・13・10の欄で「（あなたの考え）」として選んでもらう。第97条第2項ただし書の「長の予算の提出の権限を侵す」は欄にしない（下の (a)）
  • ②日数の数え方（初日を含むか）は条文に無いので、入れた日数のまま比べる
  • ③「当たりません」は、その条に当たらないと言うだけで、反対の結論を言うものではない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例・通達・行政実例：条文だけを読むアプリのため
  • 政令（第211条第2項の説明書、第220条第1項の基準、第233条第1項・第5項の書類、継続費の逓次繰越しなど）：読んでいないため
  • 第176条・第177条（再議）と第179条（専決処分）：再議・不信任・専決処分のページの範囲のため
  • 第208条〜第210条・第211条第2項・第212条第2項・第213条第2項・第215条・第216条・第218条第4項・第220条第1項・第221条・第222条第2項・第233条第4項：判定に使わないため。会計年度・繰越明許費・継続費・款と項などの語は、判定ページの欄の説明に平易に書いた
  • 第233条の2（歳計剰余金）：依頼の範囲の外のため
  • 他の法律：読んでいないため
  • 改正の経過措置（附則）：本則の範囲だけを読むため。附則に同じ番号の第211条・第212条があるが読まない

条文だけで決まらなかった点（26点）：

  • （a）第97条第2項ただし書の「長の予算の提出の権限を侵す」の範囲 → どこまで増やすと侵すかは条文に書いていない。欄にせず、7の欄で「増額して議決した」を選んだら、「議会は、予算を増額して議決できます」（本文）と「議会は、長の予算の提出の権限を侵せません」（ただし書）の2つを答える
  • （b）第283条第1項の「この法律又は政令で特別の定めをするものを除くほか」→ 第211条に関わる特別の定めを全部は読んでいない。本則は語で探した（第二百十一条を引く条は第122条だけで特別区の話ではない。特別区と予算の語を両方持つ条は第291条の9の広域連合の分賦金だけ）。政令と他の法律は読んでいない。2026-11-04 に第283条第1項を読んだ範囲だけで、1の欄で特別区を選ぶと「その他の市」の20日で答える。第211条が第二編にあることは XML の編で確かめる
  • （c）第211条第1項の「提出するようにしなければならない」に遅れたときの効果 → 書いていない。「足りません」で止め、議決の効力がなくなるとは出さない
  • （d）第235条の5 の閉鎖日から数える「三箇月以内」の終わりの日 → 条文に日付が無い。5月31日から3か月を数えた翌年度の8月31日は、このページで数えた日で、例の名前にだけ使う。名古屋市「年間の財務の流れ」（2026年11月25日に取得）も「出納閉鎖後3ヶ月以内(8月31日まで)」と書く。期間の数え方を定めた他の法律は読んでいない
  • （e）継続費の逓次繰越し → 継続費の年割額を翌年度に送る定めは施行令にあり、このページは施行令を読んでいない。14の欄で「予算で総額と各年度の額を定めた」を選んだら、11の欄が「繰越明許費ではない」で事故繰越しでなくても、「翌年度に使えません」と言い切らず、翌年度に使えるかの答えを出さない
  • （f）第220条第3項ただし書の括弧の中（関連して支出を要する経費の金額）→ 欄にしない。「事業の遂行上の必要に基づき関連して」に当たるかは条文に中身が無いため
  • （g）第112条第1項ただし書の「予算については」→ 年度の予算・補正予算・暫定予算を分けていないので、全部に掛かると読む。6の欄で「予算」を選んだら「出せません」と答え、法に反する提出も起きうる事実なので「この組み合わせはありません」にしない
  • （h）議員が出す条例案と第222条第1項 → 第222条第1項の主語は長で、議員の提出は書いていない。6の欄の議案は第112条だけで見る
  • （i）第211条第1項の「三十日」「二十日」の日の数え方 → 書いていない。3の欄に入れた日数のまま比べる（約束事②）。3の欄が空なら、日数を聞かずに期限だけを出す
  • （j）第211条第1項の指定都市（第二百五十二条の十九第一項）→ その条は読んでいない。指定都市に当たるかは1の欄で選ぶ
  • （k）年度開始前に議決が得られなかったとき → 第211条第1項に書いていない。暫定予算は2の欄で選ぶ
  • （l）第218条第1項の「調製後に生じた事由」「必要が生じたとき」、第218条第2項の「必要に応じて」、第218条第3項の「成立したとき」→ 長が補正予算・暫定予算を出したこと自体が、長が必要と判断したことを示すと読む（約束事①）。条文が外から確かめられる形で書いている「調製後に生じた事由」は4の欄で、「成立したとき」は5の欄で事実として聞く
  • （m）第219条第2項の「再議その他の措置を講ずる必要がないと認める」→ 9の欄で長が再議にかけずに受け取ったかを事実として聞く（約束事①）。8の欄に日数があれば、3日を過ぎて送られても、送られた予算として第219条第2項を当てる。再議の中身は再議・不信任・専決処分のページの話で、ここでは作り直さない
  • （n）第222条第1項の「適確に」「見込みが得られる」→ 条文に中身が無いので、10の欄で「（あなたの考え）」として聞く。名古屋市「年間の財務の流れ」（2026年11月25日に取得）は「必要な予算上の措置が適格に講ぜられる見込みが得られる(具体的には関係予算が議会に提出されたとき)までの間は、これを議会に提出してはなりません。」と書く。条文に無い読みなので、参考として置くだけで判定には使わない。第222条第1項に反して出した案件の効力は書いていない
  • （o）第220条第2項の「各項の間」→ 同じ款の中の項の間と読む。款をまたぐ移し替えは「款と款の間で移す」を選ぶものとして、移せないと答える
  • （p）第213条の繰越明許費か → 予算の定めで決まるので11の欄で選ぶ。繰り越しの後の手続は読んでいない
  • （q）第220条第3項ただし書の「支出負担行為」→ 定義の条は読んでいない。「支払いのもとになる契約など」と言葉の普通の意味で書いた
  • （r）第217条の予備費を充てられるか → 第1項は「充てるため」、第2項は「充てることができない」と書く。否決していない使い道なら第1項で充てられると読む。19の欄で予備費を計上していないのに、18の欄で予備費から出すときは「この組み合わせはありません」とする（上のウ）。手続は読んでいない
  • （s）第214条の「翌年度以降」→ 条文にこの語は無く、20の欄の語にも使わない。範囲内かは20の欄で選ぶ
  • （t）第212条第1項の「その履行に数年度を要する」→ 14の欄で何年度かにわたって払う事件があるかを選ぶ。第212条第1項によらない払い方があるかは出さない
  • （u）第233条第1項の3か月を過ぎたときの効果 → 書いていない。「期限を過ぎています」で止める
  • （v）第233条第3項の「次の通常予算を議する会議」がいつか、審査や意見なしで認定に付したときの効果 → 書いていない。「先に監査委員の審査に付さなければなりません」「意見を付けて付さなければなりません」とだけ出す。認定に付したときは、第233条第5項・第6項の書類と公表も出す
  • （w）第233条第7項の「必要と認める措置」と、否決の効果 → 措置をとったかは25の欄で選ぶ。第233条第7項は報告と公表を書くだけで、決算や支出の効力がなくなるとは書いていない。そう答えない
  • （x）第220条第3項と「余ったお金」→ 第220条第3項が書いているのは歳出予算の経費の金額。決算で余った剰余金は第233条の2の話で、依頼の範囲の外なのでルールにしていない
  • （y）第233条第2項の監査委員の審査の中身、第233条第1項・第5項の書類 → 政令を読んでいない。審査に付したかは22の欄で選ぶ
  • （z）「長」「認定」「決算」「要領」「款」「項」の平易な説明 → 条文に定義が無い語は言葉の普通の意味で、判定ページの欄の説明に書いた。「長」が知事・市長などを指すことも、読んだ条文の範囲には書いていない
