収録範囲・仕組み

「基本手当を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

雇用保険法の本則のうち、第10条の4、第13条〜第15条、第19条〜第23条、第32条〜第34条をルールにしています。

起きたことと、あなたの考えを聞く22個の欄から、同じ入力でこれらの条を全部当てます。話を先に選ばせることはせず、欄を出したり消したりもしません。小見出し（辞めたとき・何日分・いつまで・ハローワークでの手続き・受けている間のこと）は欄の並びの目印です。その話で使わない欄は、判定で見ないだけです（下の「話ごとに見る欄」）。

判定について：

  • 「失業」「自己の労働によつて収入を得た」「正当な理由」「自己の責めに帰すべき重大な理由」「やむを得ない理由」「不適当」「偽りその他不正の行為」に当たるか、就職が困難な人か、辞めた理由が第23条第2項各号や特定理由離職者に当たるかは、このアプリでは判定しません。欄名や選択肢に「（あなたの考え）」とあるものは、本人がそう考えたとして答えます。自営や請負、内職が「自己の労働」に当たるかも判定しません。個別のことは公共職業安定所（ハローワーク）に聞いてください。
  • 条文だけを読んでいます。判例と業務取扱要領は載せません。金額（賃金日額・基本手当の日額・第19条の控除額）と、被保険者期間・算定基礎期間の計算はしません。3の欄・6の欄・16の欄は、本人が数えた結果・計算した結果を受けます。
  • 厚生労働省令と附則は読んでいません。条文が「厚生労働省令で定める」と書いている中身と、本則以外の定めは判定に入れていません。延長給付も載せていません。実際の日数はここと違うことがあります。附則第4条に、特定理由離職者の一部を、離職の日によって特定受給資格者とみなす暫定の定めがあります（原文：第十三条第三項に規定する特定理由離職者（厚生労働省令で定める者に限る。）であつて、受給資格に係る離職の日が平成二十一年三月三十一日から令和九年三月三十一日までの間（附則第十一条の三第一項において「特定期間」という。）であるものに係る基本手当の支給については、当該受給資格者（第二十二条第二項に規定する受給資格者を除く。）を第二十三条第二項に規定する特定受給資格者とみなして第二十条、第二十二条及び第二十三条第一項の規定を適用する。）。ハローワークの「基本手当の所定給付日数」は、※補足1で「特定理由離職者のうち「特定理由離職者の範囲」の1に該当する方については、受給資格に係る離職の日が2009年3月31日から2027年3月31日までの間にある方に限り、所定給付日数が特定受給資格者と同様となります。」と書いています。このアプリは本則の日数で答え、1の欄の説明にこのことを書きました。
  • 第33条第1項の支給しない期間は、条文では「一箇月以上三箇月以内の間で公共職業安定所長の定める期間」で、このアプリは条文どおりこの幅で答えます。ハローワークの「よくあるご質問（雇用保険について）」は「正当な理由のない自己都合によって離職された方の給付制限期間は、離職日が令和７年４月１日以降である場合は原則１か月、同年３月 31日以前である場合は原則２か月となります。ただし、離職日からさかのぼって５年間のうちに２回以上正当な理由なく自己都合離職し受給資格決定を受けた場合または自己の責めに帰すべき重大な理由によって解雇された（いわゆる重責解雇）場合の給付制限期間は３ヵ月となります。」と書いています（業務取扱要領の側の値です）。
  • 第23条第1項第5号イ（30歳未満で、算定基礎期間が10年以上）は、条文どおり180日と答えます。ハローワークの「基本手当の所定給付日数」の表では、30歳未満で20年以上の欄は「―」です。範囲の条文にこの組を除く定めは無いので、「この組み合わせはありません」にはしていません。
  • 結論の箱には判定だけを書きます。入力した事実（「〜ので」の理由）と、条文の読みは、論理の木の行にだけ置いています。

話ごとに見る欄：受給資格の答えはいつも出します。受給資格が無いときは、受給資格の答えだけを出し、ほかの話（第15条・第19条〜第23条・第32条〜第34条・第10条の4）は出しません。どれも受給資格者に当てる条だからです。頭の欄が「無い」側（いいえ・した・7日以上・行けた・得ていない・断っていない・していない）なら、その話の答えを出しません。

話頭の欄そのほかに見る欄
受給資格（第13条）（いつも出す）1・2・3・4（4は算定対象期間の答え）
何日分・いつまで（第20条・第22条・第23条）（受給資格があれば出す）・8・9・101（倒産・解雇なら特定受給資格者）・5・6・7
ハローワークでの手続き（第15条・第21条）11・12・13・1414は11が「した」のときだけ見る
受けている間のこと（第19条・第32条〜第34条・第10条の4）15・17・18・20・1（重大な理由の解雇・自分の都合のとき）16（15が「得ていない」以外のとき）・19（1が重大な理由の解雇・自分の都合のとき）・21・10の2（20が「していない」以外のとき）

次の3つの組は、条文の上で成り立たないので「この組み合わせはありません」と答えます。どれも11の欄が「していない」（求職の申込みをしていない）組です。13の欄が「行けた」以外（第15条第2項・第15条第4項）。15の欄が「得ていない」以外（第15条第2項・第19条第1項）。12の欄が「7日に足りない」（第15条第2項・第21条）。11の欄が「していない」で14の欄が「していない」の組は、14の欄を見ないだけにしています。

載せたが事実を聞かない条：第15条第3項（失業の認定は、受給資格者が離職後最初に出頭した日から起算して四週間に一回ずつ直前の二十八日の各日について行う）は、利用者に聞く事実が無いので、欄で聞かず、判定にも使っていません。第14条（被保険者期間の数え方）・第15条第1項（基本手当は失業の認定を受けた日について支給する）・第23条第2項（特定受給資格者の定義）・第33条第3項（支給しない期間があるときの受給期間の延長）も、原文は載せていますが答えには使っていません。第14条は3の欄の数え方、第23条第2項は1の欄の選択肢の元で、第33条第3項は日数の計算をしないためです。原文は下の地図のマスで開けます。

そのほかに入っていないもの：下の載せなかったものをご覧ください。年次有給休暇は年次有給休暇のページで引いてください。

雇用保険法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（雇用保険法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • 「当たりません」「受給資格はありません」の答えは、条に当たらないと言うだけで、反対の結論を言うものではない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例と業務取扱要領：条文だけを読むアプリのため
  • 厚生労働省令の中身：法律の本則だけを読むため
  • 金額の計算（賃金日額・基本手当の日額・第19条の控除額）：入力に金額を持たず、16の欄で本人が計算した結果を受けるため
  • 第14条の被保険者期間の計算：3の欄で本人が数えた結果を受けるため
  • 第22条第3項〜第5項の算定基礎期間の計算：6の欄で本人が数えた結果を受けるため
  • 第33条第3項の受給期間の延長の計算：日数の計算をしないため
  • 延長給付（第24条〜第29条・附則）：基本手当の本則の範囲の外のため
  • 高年齢・短期雇用特例・日雇（第37条の2以降）：別の給付のため
  • 就職促進給付・教育訓練給付・育児休業給付：基本手当ではないため
  • 第10条の4第2項の事業主等の連帯：受給する本人に向けたページのため

条文だけで決まらなかった点（14点）：

  • （a）23条1項の括弧の外の特定受給資格者（算定基礎期間1年未満、第5号は5年未満）の日数は23条に書いていない → 22条1項第3号の90日に戻ると読む。これは読みです
  • （b）22条2項と23条2項の関係 → 23条2項の括弧に「前条第二項に規定する受給資格者を除く」とあるので22条2項を先に見る。5の欄が「はい」なら、1の欄が倒産・解雇でも22条2項で答える。これは読みです
  • （c）22条2項と23条1項第1号の年齢の区分に65歳以上が書いていない → 7の欄の選択肢に出さず、高年齢は載せていない。これは読みです
  • （d）33条1項の「一箇月以上三箇月以内の間で公共職業安定所長の定める期間」は何か月になるか書いていない → 数を断定せず原文の幅で答える。ハローワークの解説の値は上の「判定について」に置いた。これは読みです
  • （e）19条3項と34条1項の関係（届け出なかったら不正の行為か）は書いていない → 届け出ていないことは19条3項に当たると答え、34条1項とはつなげない。これは読みです
  • （f）3の欄は、13条の線（離職の日以前2年間で12か月・13条2項の読み替えで1年間で6か月）に合わせた3つの値にした → 12か月以上なら13条2項の括弧で13条1項とする。2年間では足りないが1年間で6か月以上のときは、1の欄が倒産・解雇・期間満了なら13条2項、ほかは13条1項に当たらないと答える。これは読みです
  • （g）22条2項は「算定基礎期間が一年以上の受給資格者にあつては次の各号」と書くので、1年未満の人が20条1項第2号に入るかが語だけでは言い切れない → 1年未満は入らないと読み、20条1項第1号にする。これは読みです
  • （h）15条2項は「しなければならない」とだけ書き、しないときの語が無い → 条文の語のまま「求職の申込みをしなければなりません」と答え、「受けられない」とは書かない。これは読みです
  • （i）15条5項は「確認して行う」とだけ書き、求職活動をしていないときの語が無い → 条文の語のまま「確認して行います」と答える。これは読みです
  • （j）10条の4第1項は「支給を受けた者」で、34条1項の「受けようとした」が無い → 受けようとしただけなら10条の4第1項に当たらないと読む。これは読みです
  • （k）33条1項第2号の括弧「正当な理由がなく自己の都合によつて退職した者に限る。次号において同じ。」→ 重大な理由の解雇で19の欄が離職の前1年・離職の後の訓練なら、除外に当たらず本文に戻す。これは読みです
  • （l）1の欄は1つだけ選ぶ → 「正当な理由のある自己都合」（特定理由離職者の側。「やむを得ない事情で辞めた」の選択肢）と「正当な理由のない自己都合」（33条1項）は、同じ離職について両立しないと読む。これは読みです
  • （m）13条2項は「二年間」「二年に」「十二箇月」だけ読み替え、「四年」を読み替えていない → 読み替えた後も上限は四年間と出す。これは読みです
  • （n）附則第4条で特定受給資格者とみなされる特定理由離職者の日数は本則に書いていない → 判定には入れず本則の日数で答える。1の欄の説明と上の「判定について」に、2027年3月31日までの離職は特定受給資格者と同じ日数になることと出典を置いた。これは読みです
