収録範囲と、入っていないもの

民法（明治二十九年法律第八十九号）の本則のうち、第三編 債権 第二章 契約 第五節 消費貸借の第587条〜第592条（第587条の2を含む）を、全部ルールにしています。第590条第1項が当てはめる（準用する）贈与の第551条は第1項の原文を、第592条ただし書が指す第402条は第2項の原文を並べています。

お金や物を借りる約束で起きた事実の11個の欄から、第587条〜第592条と第551条第1項・第402条第2項を同じ入力で全部当てます。どの条の話かを先に選ぶ欄は置いていません。個別のことは法律の専門家に聞いてください。

判定について：

  • 当てはめは判定しません。何が「書面」や「電磁的記録」に当たるか、催告で決めた期間が相当の期間か、引き渡された物が契約の内容に適合しないか、約束した種類のお金が強制通用の効力を失ったかは、事情で決まる評価です。選んだとおりとして答えています。
  • 条文だけを読んでいます。民法の消費貸借の節（第587条〜第592条）と、第590条第1項が当てはめる第551条第1項と、第592条ただし書が指す第402条第2項のほか、利息制限法・出資法・破産法と判例は読んでいません。利率に上限があるかと、破産したときのほかの扱いは、このページでは答えません。
  • 利息・損害・価額の金額と利率は聞かず、計算しません。
  • 関係のない欄（たとえば、7の欄が「時期の前」のときの8の欄）は、答えを出さないだけで、「この組み合わせはありません」にはしません。「この組み合わせはありません」になるのは、3と9、3と8、3と11、3と5、9と11、4と9と10、2と3、2と4、2と5、7と9と11の欄の組です。

語の意味：消費貸借＝借りた物を使ってしまい、同じ種類・品質・量の物を返す約束。貸主＝貸す人。借主＝借りる人。種類、品質及び数量の同じ物＝同じ種類で、同じ品質で、同じ量の物。書面でする＝紙に書いてする。電磁的記録＝メールや電子契約などの電子の記録。破産手続開始の決定＝裁判所が破産の手続を始めると決めること。効力を失う＝約束の効き目がなくなる。みなす＝そうだとして扱う。推定する＝反対のことが示されなければ、そうだとして扱う。給付する義務＝お金や物を渡したり払ったりする義務。準消費貸借＝すでにある支払いや引渡しの義務を、消費貸借に切り替える約束。特約＝特別の約束。準用＝別の定めを、合うように読み替えて当てはめること。契約の内容に適合しない＝約束した中身と合わない。価額＝その物のお金に直した値段。償還＝お金で返すこと。解除＝約束を一方からの申し出でやめること。相当の期間＝ほどよい長さの期間。催告＝するよう求めること。弁済期＝返す時期。強制通用の効力＝お金として使える力。弁済＝返すこと・払うこと。これらは条文の語をこのアプリが言い換えたものです。

載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 何が「書面」や「電磁的記録」に当たるか：事情で決まり、条文だけでは決まらないため判定しません
  • 相当の期間か、契約の内容に適合しないか、約束した種類のお金が強制通用の効力を失ったか：事情で決まり、条文だけでは決まらないため判定しません。選んだとおりとして答えます
  • 書面にしていない約束を、受け取る前にやめられるか：第587条の2第2項は書面でする消費貸借だけの定めのため判定しません
  • 貸主が受け取る前にやめられるか（第587条の2第2項のほかの定めによって）：第587条〜第592条に書いてないため判定しません。第587条の2第2項は借主だけの定めなので、結果には「587条の2第2項によっては契約の解除をすることができません」とだけ出します
  • 受け取る前に「やめたい」と言った後に受け取ったときの扱い：条文に書いてないため判定しません
  • 利息つきの消費貸借で、貸主がどんな状態の物を引き渡すと約したと扱うか：第590条第1項は特約の無い消費貸借だけの定めのため判定しません
  • 準消費貸借の利息がいつからか・引き渡す物の状態：準消費貸借では物を新しく受け取らず、第589条第2項の「受け取った日」に当たる日と、第590条第1項の前提が条文に無いため判定しません
  • 返す時期を決めたときに、貸主がいつ返還を求められるか：第591条第1項は時期を決めなかったときの定めのため判定しません
  • 返す時期の前に返したときと、返す時期を決めていないときに、約束した種類のお金が使えなくなっていたときの扱い：返す時（弁済期）がいつかが条文だけでは決まらないため判定しません
  • 利率の上限：利息制限法を読んでいないため判定しません
  • 破産したときのほかの扱い：破産法を読んでいないため判定しません
  • 第402条第1項・第3項：第592条ただし書が指すのは第2項だけのため、判定で引きません
  • 第551条第2項（負担付贈与の担保の責任）を消費貸借に当てはめるか：条文だけでは決まらないため判定しません
  • 利息・損害・価額の金額と利率：入力は選択肢で受けるため
  • 判例・解説書：条文だけを読むアプリのため
  • 附則：本則の範囲だけを読むため

条文だけで決まらなかった点（27点）：

  • （1）第587条 → 口約束で受け取ったときは、同じ種類・品質・量の物で返すと約束したものとして「効力を生じます」と答え、返す約束をしたかは聞かない
  • （2）結論の箱の並び → 条の順（第587条・第587条の2第1項・第588条→第587条の2第2項→第587条の2第3項→第589条→第590条→第591条→第592条）に並べる。成り立つか（第587条・第587条の2第1項・第588条）がいつも一番上になる
  • （3）第587条 → 口約束でまだ受け取っていないときは「消費貸借は成り立っていません」（第587条）だけを出し、第587条の2・第589条〜第592条の段を出さない。成り立っていない約束に利息などの条文の文を並べないため。これは読みです
  • （4）第587条の2第2項 → 受け取る前の解除の段は、書面・電磁的記録の約束で、まだ受け取っておらず、借主が「やめたい」と言ったときだけ出す。口約束のときは、第2項が書面でする消費貸借だけの定めなので段を出さない
  • （5）第587条の2第2項 → 貸主が受け取る前に「やめたい」と言ったときは、第2項が解除を認めているのは借主なので「貸主は、587条の2第2項によっては契約の解除をすることができません」と書く。段を出すのは、借主が言ったときと同じ組（書面・電磁的記録の約束で、まだ受け取っておらず、効力を失っていない）だけ
  • （6）第587条の2第2項 → 前段（借主は受け取るまで解除できる）と後段（貸主は解除で受けた損害の賠償を請求できる）を別の行に出す。後段は損害の欄が「受けた」のときだけ出す。「やめたい」と言っただけでは、解除したとは書かない
  • （7）第587条の2第4項 → 電磁的記録を選んだときは、第587条の2第1項〜第3項の段の根拠に第4項を添える
  • （8）第587条の2第3項 → 破産手続開始の決定は貸主・借主のどちらが受けても同じに扱う（「当事者の一方」）。口約束のときと、受け取った後の決定は「第587条の2第3項によっては効力を失いません」と書く
  • （9）第590条第1項・第551条 → 準用する第551条は第1項だけを並べ、第2項（負担付贈与）は判定で引かない
  • （10）第589条第2項 → 特約があってまだ受け取っていないときは「貸主が請求できるのは、借主が物を受け取った日以後の利息です」と書き、利息があるとは言い切らない
  • （11）第589条 → 利率の上限は判定しない
  • （12）第590条第1項・第551条第1項 → 当てはめる事実が無いので欄を置かず、利息の特約が無いときはいつも節に出す。問われた事実への判定ではないので、結論の箱と論理の木には入れない
  • （13）第590条第2項 → 数が足りない物は、第2項が種類又は品質に関して契約の内容に適合しない物の定めなので「借主は、590条2項によっては引き渡された物の価額を返還することができません」と書く。数が足りないときにほかの定めで何ができるかは判定しない
  • （14）第591条第1項 → 返す時期を決めたときに、貸主がいつ返還を求められるかは、条文に書いていないため段を出さない
  • （15）第591条第1項 → 「相当の期間を定めて返還の催告をすることができる」とだけ書き、すぐ返してと求められるかは書かない
  • （16）第591条第3項 → 時期を決めていないときと、時期が来てから返したときは「第591条第3項によっては損害の賠償を請求することができません」と書く
  • （17）第592条ただし書・第402条第2項 → 「約束した種類のお金が、返す時に使えなくなっていた」は、返す時期が来たときだけ段に出し、第592条ただし書と第402条第2項（他の通貨で弁済する）を1つの行で答える。返す時期の前に返したときと、返す時期を決めていないときは、返す時（弁済期）がいつかが条文だけでは決まらないため段を出さない
  • （18）第588条 → 準消費貸借は、書面かを聞かずに「成立したものとみなす」と答える。準消費貸借のときに受け取った物・受け取る前にやめたいと言った人・破産手続開始の決定を選ぶと「この組み合わせはありません」（第588条）にする。準消費貸借は物を新しく受け取らずに成り立つと読み、根拠に第588条を当てた。これは条文の文言から直接出ない読みです。準消費貸借のときは、第590条第1項（引き渡す物の状態）の段を出さない。利息の特約があるときは第589条第2項で「利息を請求することができます」とだけ答え、いつからの利息かは書かない。第589条第2項の「受け取った日」が準消費貸借で何に当たるかは条文に書いていないため
  • （19）第587条の2第1項 → 書面・電磁的記録のときは、受け取ったかにかかわらず「効力を生じます」と答える
  • （20）論理の木の印 → 成り立っていない・効力を失う・効力を失わない・利息を請求できない・受け取った日以後・貸主は解除できない・価額を返還できない・この限りでない・損害の賠償を請求できない・この組み合わせはありません、のときは「・」、ほかは「◯」
  • （21）語の開き方 → 上の「語の意味」の言い換えと、条文ごとの言い換え（16行）は、このアプリの言葉
  • （22）利息制限法・出資法・破産法・判例・第402条第1項・第3項 → 読んでいないので判定しない
  • （23）受け取る前に「やめたい」と言った人がいて、その後に受け取った → 「この組み合わせはありません」にせず、第587条の2第2項の段を出さない。受け取る前にやめたいと言った後に受け取ったときの扱いは、条文に書いていないため
  • （24）消費貸借が終わったとき（受け取る前の破産手続開始の決定で効力を失った・受け取る前に借主が解除して貸主が損害を受けた）→ 第589条〜第592条の段を出さない。条文に「終わった後は」という語は無い。これは読みです
  • （25）まだ受け取っていない × 返した・「返して」と求めた → 「この組み合わせはありません」（第587条・第587条の2第1項）。第587条の2第1項の「その受け取った物と種類、品質及び数量の同じ物をもって返還」から、返還は受け取った物と同じ物ですると読んだ。これは読みです
  • （26）損害の欄 → 第587条の2第2項後段（受け取る前の解除）と第591条第3項（返す時期の前の返還）の損害を1つの欄で聞く。受け取ったかの欄でどちらか一方に決まるため
  • （27）返した × 返せなくなった → 「この組み合わせはありません」（第592条）。約束した種類のお金が使えなくなっていたときは、第402条第2項で他の通貨で返すので、返したと並べてよく、組み合わせなしにしない
