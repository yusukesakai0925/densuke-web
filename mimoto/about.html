収録範囲・仕組み

「身元保証法を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

身元保証ニ関スル法律（昭和八年法律第四十二号）の本則の第1条〜第6条を、全部ルールにしています。

収録しているのは「身元保証契約か」「保証が続く期間と更新」「会社が保証人に知らせること・保証人が保証をやめること」「保証人が払う額と特約」です。裁判所などでどうなるかを当てる道具ではなく、条文がどう定めているかを確かめるものです。個別のことは法律の専門家に聞いてください。

この XML は2026年11月10日に取得した版で、それ以後の改正と、公布済みで施行前の改正は読んでいません。

条文はカタカナの文語です。判定ページでは原文をそのまま並べ、その横にこのアプリの言い換えを置いています。原文は直していません。

民法（保証・極度額・書面）・労働基準法・判例は読んでいません。民法の保証（極度額・書面の決まりを含む）は保証の効力と求償のページで引いてください。雇われている本人と会社の雇用の契約そのものは雇用（民法）のページで引いてください。

保証人が払う額は、第5条により裁判所が一切の事情を考え合わせて決めます。このページは額も割合も計算しません。

附則（施行期日）は読んでいません。

判定ページは10個の欄をいつも全部出し、選んだ値によって欄を出したり消したりしません。入力に関わらない欄は、判定で見ないだけです。4つの小見出しの答えは、同じ入力で全部出します。

  • 2〜10の欄：1の欄が「本人の身柄を引き取るだけで、損害は払わない」なら見ません。1条の答え（身元保証契約に当たりません）だけを出します（第2条〜第6条は、どれも身元保証契約の条のため。下の (1)）
  • 3の欄（雇われ方）：2の欄に年を入れたときは、答えを変えません（期間を決めたときの上限は第2条第1項の5年で、見習いの例外が無いため。下の (3)）
  • 5の欄（更新した後の期間）：4の欄が「していない」か「自動で更新すると書いてあるだけ」なら見ません。4の欄が「決め直した」で5の欄が空なら、「判定できませんでした」と出します
  • 8の欄（保証人の知り方）：6の欄が「問題は無い」で、7の欄が「変えていない」か「変えたが、責任も見守りやすさも変わらない」なら見ません（下の (14)）

「この組み合わせはありません」と出すのは2つの組です。ア：1の欄が「本人の身柄を引き取るだけで、損害は払わない」で、10の欄が「「損害は全額保証人が払う」と書いてある」（1条。「全額払う」と書いたなら損害を払う約束をしていて、損害を払うと約束した契約は、呼び名が何でも身元保証契約です）。イ：6の欄が「同じことがあるが、会社はまだ知らない」で、7の欄が「変えていない」か「変えたが、責任も見守りやすさも変わらない」で、8の欄が「会社からの知らせで知った」（3条1号・3条2号。会社が知らせるのは、第1号の事実を知ったときと、第2号の変更をしたときで、会社がまだ知らない事実を会社が知らせることはできません。7の欄が「変え、保証人の責任が重くなるか、保証人が本人を見守るのが難しくなった」なら、会社は自分で変えたことを知らせられるので、イに入れません。下の (24)）。2の欄が空（期間を決めていない）で4の欄が「自動で更新すると書いてあるだけ」の組と、引き取るだけの約束で損害が出た組は、起きうる事実なので段の答えで出します。

入っていないもの：当てはめ（商工業見習者か・仕事に向かない・不誠実か・責任が重くなるか。上の約束事①）、会社が知らせなかったときにどうなるか、額と割合の計算、保証人が亡くなったとき、民法（極度額・書面）・労働基準法・判例。詳しくは載せなかったものをご覧ください。

この法律のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました（この法律に章はありません）。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（この法律の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • ①第1条ただし書「商工業見習者」、第3条第1号「業務上不適任又ハ不誠実ナル事跡」「責任ヲ惹起スル虞」、第3条第2号「責任ヲ加重シ又ハ其ノ監督ヲ困難ナラシムル」は、条文に中身が書いていないので、このアプリは当てはめを判定しない。判定ページでは、3の欄（見習いとして雇われたか）と7の欄（責任が重くなるか・見守るのが難しくなるか）を「（あなたの考え）」として、6の欄を事実の例（使い込み・無断欠勤が続く など）を添えて選んでもらう。1の欄の「呼び名が「身元保証」「身元引受」「保証」など何でも」は、第1条の「引受、保証其ノ他名称ノ如何ヲ問ハズ」を身元保証契約の定義として読んだもの（下の (1)）
  • ②期間は年の整数（1〜99年）で聞き、月・日は聞かない（下の (8)）
  • ③「当たりません」は、その条に当たらないと言うだけで、反対の結論を言うものではない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 民法の保証・極度額（保証の上限の額）・書面の決まり：別の法律で、読んでいないため判定しません。保証の効力と求償のページで引けます
  • 会社が知らせなかったときにどうなるか：この法律の条文に書いてなく、判例は読んでいないため判定しません。第3条第1号・第2号の「知らせなければなりません」までを答えます（下の (18)）
  • 保証人が払う額・割合：第5条で裁判所が事情を見て決めるため、計算しません
  • 自動で更新する特約が効くか・「全額払う」特約がどこまで効くか：条文に文が無いため、条文の文だけを答え、解説の読みは下の (7)・(20) に出典つきで置きます
  • 保証人が亡くなったとき：この法律の条文に書いてないため判定しません
  • 第3条第1号・第2号に当たらない理由で保証をやめられるか：この法律に定めが無いため判定しません（下の (17)）
  • 商工業見習者・不誠実などの当てはめ：事情で決まり、条文だけでは決まらないため判定しません（上の約束事①）
  • 月・日の数え方：年の整数だけで聞くため（上の約束事②）
  • 労働基準法・判例・解説書：条文だけを読むアプリのため。下の読みで出典を示した解説は、読みを確かめるのに使っただけです
  • 雇用の契約そのもの：別の法律のため。雇用（民法）のページで引けます
  • 附則（施行期日）：本則の範囲だけを読むため

条文だけで決まらなかった点（24点）：

  • （1）第1条 → 1の欄で、損害を払うと約束したかを聞く。「引受、保証其ノ他名称ノ如何ヲ問ハズ」から、呼び名が何でも、損害を払うと約束した契約は身元保証契約と読む。身柄を引き取るだけの約束は第1条に当たらないと答え、第2条〜第6条の答えも出さない（どれも身元保証契約の条のため）。「損害は全額保証人が払う」と書いた組は、損害を払う約束をしているので「この組み合わせはありません（1条）」とする（上のア）。期間を決めたかは2の欄を空にするかで聞き、商工業見習者かは3の欄で「（あなたの考え）」として聞く
  • （2）第2条第1項 → 5年より長い期間は5年に縮み、契約は無効にならないと書く。旭合同法律事務所「身元保証人の責任」（2024.03.13）も「期間の定めのある身元保証は，存続期間が５年であり，これより長い期間を定めても５年間に短縮されます（法2条1項）。」と書く
  • （3）第1条ただし書の5年 → 期間を決めていないときだけの定めと読む。期間を決めたときは見習者でも上限は第2条第1項の5年（第2条に見習いの例外が無い）
  • （4）第2条第2項の「超ユルコトヲ得ズ」→ 更新した後の期間を5年より長く決めたときは、「更新した後の期間は、更新の時から5年を超えられません」と条文の文だけを答え、5年に縮むとは言い切らない。縮むと書いてあるのは第2条第1項だけ。前の版のこのアプリは「第2条第1項と同じく5年に縮むと読みます」と答えていた
  • （5）更新したとき → 1〜3の欄の答え（もとの契約の期間）と、4・5の欄の答え（更新した後の期間）を、別の答えとして並べる。前の版のこのアプリは、更新した後の期間を一番上に置いていた
  • （6）更新 → 更新の回数と、更新する前の期間の残りは聞かない
  • （7）自動で更新する特約 → 4の欄で「契約に「期間が終わったら自動で更新する」と書いてあるだけで、決め直してはいない」を選んだときは、条文の文だけ「身元保証契約は更新できます。更新した後の期間は、更新の時から5年を超えられません（2条2項）」を答える。条文に自動の更新の文は無い。解説は3件とも、自動の更新はできないと書く。ベリーベスト法律事務所「雇用時に身元保証書の提出を求めるには？ 作成・運用の法的ルール」（更新日 2025年06月25日）「身元保証契約の自動更新はできませんので「契約期間の満了時に異議がないときは更新する」などの自動更新規定があったとしても、基本的には無効です。」。弁護士法人ALG&Associates 大阪法律事務所「身元保証と身元保証法について」（更新日 2021/12/28）「身元保証書の自動更新はできませんので、更新をする場合は、改めて手続きをしてもらう必要があります。」。旭合同法律事務所「身元保証人の責任」「同様の趣旨で，更新予約や自動更新もできません。」。前の版のこのアプリは、判定しないで止めていた
  • （8）期間の単位 → 年の整数（1〜99年）だけで聞き、月・日は聞かない（上の約束事②）
  • （9）第6条の「身元保証人ニ不利益」と期間 → 5年より長い期間を決めたときは、第2条第1項が「五年ニ短縮ス」と効果を決めているので、第6条の答えを出さない（「契約は無効になりません」と食い違って読めるため）。前の版のこのアプリは、第6条の対象と書いていた
  • （10）第3条第1号の「知リタルトキ」→ 6の欄で、会社が知ったか、まだ知らないかを分ける。会社がまだ知らないときは「会社が知るまでは、第3条第1号で保証人へ知らせる義務はありません」と答える
  • （11）第3条第2号の「其ノ監督」→ 保証人が本人を監督すること、と読む。条文ごとの言い換え（3条2号）も同じ読みで書き、7の欄では「見守る」と言い換えた。弁護士法人ALG&Associates の解説も「身元保証人の責任が重くなり、また身元保証人による労働者の監督が困難になると認められる場合」と書く
  • （12）第3条第2号 → 仕事か勤め先が変わっても、責任が重くならず監督も難しくならないなら当たらない
  • （13）第4条の「前条第一号及第二号ノ事実」→ 第1号か第2号のどちらかの事実があればよいと読む（「及」を両方そろう意味に読まない）
  • （14）第4条の「前条ノ通知」→ 第3条第1号・第2号に当たる事実の知らせだけを指すと読む。6の欄が「問題は無い」で、7の欄が「変えていない」か「変えたが、責任も見守りやすさも変わらない」なら、8の欄（知り方）を見ない
  • （15）第4条 → 保証人が事実をまだ知らないときは、「保証人は、会社から知らせを受けたとき、または自分で事実を知ったときに、これから先に向けて保証をやめられます」と答える
  • （16）第4条の「将来ニ向テ」→ やめる前に起きた損害の分は消えないと書く
  • （17）第3条第1号・第2号に当たらない理由でやめられるか → この法律に定めが無い。7の欄で変えたが変わらないときは「保証人は、第4条では保証をやめられません」と答え、ほかの理由でやめられるかは判定しない
  • （18）会社が知らせなかったとき → 条文に定めが無い。6の欄が「会社が知った」で8の欄が知らせでないときも、第3条第1号の「知らせなければなりません」だけを答える。解説は、第5条の「一切の事情」の側の話として書く。旭合同法律事務所「身元保証人の責任」「通知義務を懈怠したとしても，身元保証人の責任が免責されるわけではありませんが，責任の範囲を限定する際の一事情として考慮されます。」。ベリーベスト法律事務所の解説「このような通知を怠ると、労働者の行為により会社に損害が発生したとしても、身元保証人に賠償を求めることができない可能性がありますので注意が必要です。」
  • （19）第5条 → 9の欄で損害が出たときだけ答え、額も割合も計算せず、条文が挙げる事情を並べる
  • （20）「全額払う」特約 → 「この法律の定めに反して保証人に不利な特約は無効です。保証人が払う額は、裁判所が第5条の事情を考え合わせて決めます（6条・5条）」と答え、特約が無効だとは言い切らない。損害が出ていなくても、特約は損害の前から決まっているので答えを出す。解説も、額は裁判所が決めると書く。ベリーベスト法律事務所の解説「身元保証人といっても労働者の行為により生じた損害の全額を負わせることができるわけではありません。身元保証人が負う賠償額は、最終的には裁判所が決定します。」。弁護士法人ALG&Associates の解説「限度額をいくら高く設定したとしても、実際に従業員が何らかの損害を起こした場合には、最終的にはその限度額の範囲の中で、裁判所が損害賠償額を決定することになります。」。前の版のこのアプリは、判定しないで止めていた
  • （21）語の開き方 → 欄の説明（本人＝被用者・会社＝使用者・更新・特約）と、「商工業見習者」を「商店や工場などで、仕事を覚える見習い」、「業務上不適任又ハ不誠実ナル事跡」を「仕事に向かないことか不誠実なこと（使い込み・無断欠勤が続く など）」と開いた語、条文ごとの言い換え（9行）は、このアプリの言葉
  • （22）極度額・書面・保証人が亡くなったとき → この法律の条文に無いので判定しない。極度額と書面は民法の決まりで、保証の効力と求償のページで引ける
  • （23）第4条の「前条第一号…ノ事実」→ 第1号の事実は、本人の仕事に向かない・不誠実な事跡のことと読み、会社が知ったか（第3条第1号の「知リタルトキ」）を含めない。会社が知ったかは、第3条の会社が知らせる義務の起点と読む。6の欄が「会社はまだ知らない」でも、保証人が自分で知れば第4条で保証をやめられると答える
  • （24）第3条の「知リタルトキ」と第4条の「前条ノ通知」→ 6の欄が「会社はまだ知らない」で、7の欄が「重く」でない（変えていない・変えたが変わらない）のに、8の欄で「会社からの知らせで知った」を選んだ組は、会社が知らない事実を会社が知らせたことになるので「この組み合わせはありません（3条1号・3条2号）」とする（上のイ）。7の欄が「重く」なら、会社は第3条第2号で自分で変えたことを知らせられるので、ありませんにしない
