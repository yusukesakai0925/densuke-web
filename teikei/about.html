収録範囲と、入っていないもの

民法（明治二十九年法律第八十九号）の本則のうち、第548条の2〜第548条の4（定型約款）と第1条第2項（基本原則）をルールにしています。

取引と約款で起きた事実と、あなたの考えを聞く17個の欄から、第548条の2〜第548条の4を同じ入力で全部当てます。どの条の話かを先に選ぶ欄は置いていません。個別のことは法律の専門家に聞いてください。

この XML は2026年11月3日に手元に置いた版で、それ以後の改正と、公布済みで施行前の改正は読んでいません。

判定ページでは原文をそのまま並べ、その横にこのアプリの言い換えを置いています。原文は直していません。

消費者契約法、民法の定型約款のほかの条、判例・立案担当者の解説は読んでいません。何の契約書・規約が定型約款に当たるかの一覧は作っていません。

第548条の4第2項の周知の義務は第1項の変更全部にかかりますが、「周知しなければ効力を生じない」の第3項は第1項第2号の変更だけです。手元の XML の文に従っています。

附則と改正法の経過措置は読んでいません。

入っていないもの：下の載せなかったものをご覧ください。

判定について：

  • 欄名の後ろに「（あなたの考え）」と書いた4つの欄（2：取引の内容が画一的であることは双方に合理的か、10：問題の条項は基本原則に反して相手の利益を一方的に害するか、12：変更は相手の一般の利益に適合するか、14：変更は事情に照らして合理的か）は、事情で決まる評価で、条文だけでは決まりません。このアプリは当たるかを判定せず、選んだあなたの考えのとおりに答えます。
  • 当てはめは判定しません。どの契約書・規約が定型約款に当たるか、「相当の期間」「遅滞なく」「相当な方法」「正当な事由」に当たるかも、選んだとおりとして答えています。
  • 条文だけを読んでいます。第548条の2〜第548条の4と第1条第2項のほか、消費者契約法、判例・立案担当者の解説は読んでいません。第548条の3第1項の示す義務に反したときの損害賠償などの効果、効力発生時期を定めていないときの変更の効力は、このページでは答えません。
  • 第548条の4第3項（効力発生時期が到来するまでに周知をしなければ効力を生じない）は第1項第2号の変更だけに当たるので、第1号の変更は、周知が無くても効力発生時期が来れば、変更後の条項について合意があったものとみなすと答えます。これは条文の文言に書かれておらず、第3項から反対に読んだものです。
  • 関係のない欄（たとえば、11の欄が「していない」のときの12〜14の欄）は、答えを出さないだけで、「この組み合わせはありません」にはしません。「この組み合わせはありません」になるのは、4と6、6と8、11と15、11と16、11と17、16と17の欄の組です。

語の意味：定型取引＝ある特定の者が不特定多数を相手にする取引で、内容の全部か一部が画一的であることが双方に合理的なもの。画一的＝相手ごとに変えず同じ。定型取引合意＝定型取引をする合意。定型約款＝定型取引で、契約の内容にする目的で準備された条項のまとまり。定型約款準備者＝定型約款を準備した側。相手方＝定型約款準備者の取引の相手。基本原則＝権利の行使と義務の履行は信義に従い誠実に、という第1条第2項の原則。相当の期間＝それなりの期間。遅滞なく＝遅れずに。電磁的記録＝電子データなど。正当な事由＝一時的な通信障害など、もっともな理由。一般の利益に適合する＝相手のだれにとっても利益になる。効力発生時期＝変更の効力が生じる時。周知＝インターネットなどで広く知らせること。これらは条文の語をこのアプリが言い換えたものです。

この法律のどこまでをルールにしたか（全条文の地図）

民法の本則の全条文を、編・章ごとに1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条、斜線は削除された条です。マスを押すと原文が出ます。第1条は第2項だけを読んでいるので、第2項だけが出ます。

アプリの約束事（この法律の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは、欠けた要件が分かる起きた事実の文だけを出し、反対の結論は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例・立案担当者の解説・通達：条文だけを読むアプリのため。読んでいません
  • 消費者契約法との関係：別の法律で、読んでおらず判定しません
  • 何の契約書・規約が定型約款に当たるかの一覧：当たるかどうかは1〜3の欄で利用者が選ぶため
  • 「一方的に害する」「一般の利益に適合する」「合理的」「正当な事由」に当たるか：事情で決まる評価で、条文だけでは決まらないため判定しません。選んだとおりとして答えます
  • 第548条の3第1項に反したときの損害賠償など：読む範囲に効果の定めが無いため判定しません
  • 第1号の変更で効力発生時期を定めていないときの効力：変更後の条項について合意があったものとみなす時が無く、文だけで決まらないため判定しません
  • 第2号の変更で効力発生時期を定めていないときの効力：第3項は「効力発生時期が到来するまでに」の形で、定めていないときは文だけで決まらないため判定しません
  • 「変更をすることがある旨の定め」があるか：第548条の4第1項第2号の事情の1つで、結論を変えないので欄にしていません。14の欄の説明に書いています
  • 個別の合意による契約の変更：この範囲の外のため判定しません
  • 改正の経過措置（附則）：本則の範囲だけを読むため

条文だけで決まらなかった点（29点）：

  • （1）第548条の2第1項は条項を読んだかどうかを条件にしていないと読み、読んだかどうかを欄に出さない
  • （2）第548条の2第1項 → 5の欄を「合意した／合意はないが表示していた／合意も表示もない」の3つで聞く。合意も表示もあるときは「合意した」を選び、第1号で答える（第2号を聞かない）
  • （3）定型取引・定型約款に当たらないとき（1〜3の欄）→ 第548条の2第1項の「定型約款になりません」の段だけを出し、第548条の3・第548条の4の段は出さない。第548条の3・第548条の4の主語は定型約款準備者なので、定型約款に当たらなければこの2条の段を出さない。これは読みです
  • （4）第548条の2第2項に当たるとき → その条項だけ合意をしなかったものとし、ほかの条項は第1項のままと読む。第1項の答えは「問題の条項のほかの約款の個別の条項について合意をしたものとみなされます」と書く
  • （5）第548条の2第2項の「定型取引の態様及びその実情並びに取引上の社会通念に照らして」→ 答えの文には書かず原文に任せる。「一方的に害する」は10の欄のあなたの考え
  • （6）第548条の2第2項 → 権利を制限も義務を加重もしない条項は、一方的に害すると考えても、2つが揃わないので「合意をしなかったものとはみなされません」と答える。制限も加重もせず、害するとも考えないときは、第2項の段を出さない
  • （7）第548条の3第2項で第548条の2が適用されないとき → 個別の条項について合意をしたものとはみなされないと読み、第548条の2第1項・第2項の段は出さない。契約全体がどうなるかは判定しない
  • （8）取引の合意をしていない × 合意の前に請求 × 正当な事由なく拒んだ → 第548条の3第2項の段を出さない。「第548条の2は適用されません」も「この後で合意をしても…」も書かない。取引の合意がまだ無く、第548条の2が当たる場面がまだ来ていないため。取引の合意をしたときだけ、第548条の3第2項の段を出す
  • （9）第548条の3第1項の相当の期間を過ぎてからの請求 → 第1項本文の場面に当たらず、「548条の3第1項によっては、約款の内容を示す義務を負いません」と答える。ほかの決まりは読まない
  • （10）請求の前に書面か電磁的記録を受け取っていた（第1項ただし書）× 合意の前に正当な事由なく拒んだ → 第548条の3第2項の段を出す。第2項は「前項の請求を拒んだとき」で、受け取っていたかで分けていないため。受け取っていたことが正当な事由に当たるかは、8の欄であなたが選ぶ
  • （11）正当な事由なく拒むこと → 第1項の文に「拒む」とは無いが、示す義務に反すると読む
  • （12）合意の後の請求を拒んだとき → 第2項は「定型取引合意の前において」とあるので第2項の段を出さず、第548条の2は外れないと読む
  • （13）正当な事由があって拒んだとき → 第1項の示す義務に反するかは、第2項ただし書が第2項の文で、第1項の文に正当な事由が無いので判定せず、示す義務の段だけを出す
  • （14）準備した側が約款を見せたとき → 示す義務の段を、まだ見せていないときと同じ文で出す。遅滞なく・相当な方法で見せたかは判定しない
  • （15）第548条の4第1項で第1号に当たるとき → 第2号（13・14の欄）を聞かない
  • （16）「変更をすることがある旨の定め」→ 第1項第2号の事情の1つと読み、欄にしない。14の欄の説明に事情の1つとして書く
  • （17）第1号の変更 → 第3項は第2号だけに当たるので、第1号の変更は周知が無くても効力発生時期が来れば、変更後の条項について合意があったものとみなす（第3項の反対の読み。条文の文言には書かれていない）。第2項の周知の義務に反する段はそのまま出す。効力発生時期を定めていないときは、変更後の条項の合意（効力）は判定しない
  • （18）第2号の変更で効力発生時期を定めていないとき → 第2項の義務に反すると読み、第3項で効力がどうなるかは文だけで決まらないので第3項の段を出さない
  • （19）第2号の変更で周知が効力発生時期を過ぎてからのとき → 「到来するまでに」周知していないので第3項で効力を生じないと読む。第2項の文には「まで」とは無いが、第2項の周知の義務にも反すると読む
  • （20）第548条の4第2項 → 効力発生時期が来たのに周知していないときは、周知の義務に反すると読む。効力発生時期がまだ来ておらず、まだ周知していないときは「周知しなければなりません」と書き、反するとは書かない
  • （21）周知が揃わないとき（第1号の変更で効力発生時期が来たときを除く）→ 「変更することができます」と言わず、「548条の4第1項第N号の変更の要件を満たしています」と書く
  • （22）変更後の条項の合意（第548条の4第1項の「合意があったものとみなし」）→ 効力発生時期に生じると読み、効力発生時期が来て、それまでに周知をしたとき（第1号の変更は、（17）のとおり周知が揃わなくても）に「合意があったものとみなされます」と書く。効力発生時期がまだ来ていないときは「変更の効力発生時期は、まだ来ていません」とだけ書き、時期が来たらどうなるかは書かない。第2号の変更で効力発生時期がまだ来ておらず、まだ周知していないときは、第3項の段を出さない（「来るまでに周知をしなければ、効力を生じません」は今どうなるかを言わない条件文になるため。今どうなるかは、この段と第2項の「周知しなければなりません」で答える）
  • （23）第548条の4第4項 → 15の欄の段は、第1項に当たるときだけ出す。第1項に当たらないときは第4項を出さない
  • （24）第548条の4第1項に当たらないとき → 「548条の4第1項によっては、…契約の内容を変更することはできません」とだけ答える。個別の合意による変更は判定しない
  • （25）取引の合意をしていない × 約款を変更した → 第548条の4の段を出さないだけにし、「この組み合わせはありません」にはしない。第1項の「契約の内容を変更」は契約があることを前提にしていると読めるが、文言から「ありえない」とまでは言えないため
  • （26）取引の合意をしていない × 合意の後の請求 → 「この組み合わせはありません」（第548条の3第1項）。「定型取引合意の後」の請求は、取引の合意をした後にだけあると読んだ
  • （27）請求していない × 拒んだ → 「この組み合わせはありません」（第548条の3第2項）。「前項の請求を拒んだ」は、請求があったときだけあると読んだ
  • （28）約款を変更していない × 変更で条項が入った・効力発生時期を定めた・変更の周知をした → 「この組み合わせはありません」（第548条の4第4項・第2項）。効力発生時期を定めること・周知・変更で入る条項は、第1項の変更をするときにだけあると読んだ
  • （29）効力発生時期を定めていない × 効力発生時期までに・過ぎてから周知、効力発生時期がまだ来ていない × 過ぎてから周知 → 「この組み合わせはありません」（第548条の4第2項・第3項）。「効力発生時期が到来するまでに」は効力発生時期を定めたときにだけ言え、時期が来る前に「過ぎてから」はないと読んだ。効力発生時期を定めずに周知をした、という事実はこの欄では入れられない
