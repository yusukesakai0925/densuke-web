収録範囲・仕組み

「再議・不信任・専決処分を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

地方自治法の本則のうち、第176条〜第180条をルールにしています。

収録しているのは「議会の議決・選挙に長が異議や違反を示したときの再議と、その後の審査・裁定・訴え」「予算から義務の経費・災害の経費を削る・減らす議決の再議」「長の不信任の議決と、議会の解散・長が職を失うこと」「長が議会に代わってする処分と、議会への報告・承認」です。

入っていないもの：議決に本当に異議があるか・本当に違法か・本当に緊急か（どれも長の認識が要件で、このアプリは長が示した理由・長の判断を事実として聞くだけです。下の約束事①）、判例・行政実例、会議規則、第113条・第162条・第252条の20の2 の中身、地方公営企業など別の法律の再議。詳しくは載せなかったものをご覧ください。同じ地方自治法の住民監査請求は住民監査請求のページで引いてください。

判定ページは22個の欄をいつも全部出し、選んだ値によって欄を出したり消したり、欄の名前を変えたりしません。入力に関わらない欄は、判定で見ないだけです。3つの小見出しの答えは、同じ入力で全部出します。

  • 4の欄（再議に付した日までの日数）：3の欄が「議決に異議がある」でなければ見ません。空なら、まだ付していないとして10日の期限だけを出します
  • 6・7の欄（再議の議決の出席・賛成）：3の欄が「議決に異議がある」で、5の欄が「前と同じ議決・選挙をした」で、2の欄が条例・予算（経費を削る・減らす議決を含む）のときだけ見ます。どちらかが空なら、確定するかの答えを出しません
  • 8の欄（審査を申し立てた日までの日数）：空なら、申し立てていないとして21日の期限だけを出します
  • 9〜11の欄（裁定・訴え）：審査を21日以内に申し立てたときだけ見ます。10の欄が空なら、訴えを起こしていないとして60日の期限だけを出します。11の欄は、60日以内に訴えを起こしたときだけ見ます
  • 13〜17の欄（不信任の議決の数・解散・通知）：12の欄が「していない」なら見ません。13〜15の欄のどれかが空か、議員数が0なら、不信任の答えを出しません。17の欄が空なら、通知はまだとして10日の期限だけを出します。12の欄が「解散のあと初めて招集された議会で、再びした」なら、16・17の欄は見ません（下の (18)）
  • 18〜20の欄（事件・議会・中身）：19の欄が「開ける」なら、179条の答えを出しません（22の欄で処分していて、21の欄が「指定していない」ときを除く。下の (28)）
  • 21・22の欄（議会の指定・処分と報告）：21の欄で指定しているなら、19の欄に関わらず180条の答えを出します（下の (25)）

「この組み合わせはありません」と出すのは11の組です。ア：2の欄が「議会がした選挙」で、3の欄が「議決に異議がある」（176条1項。異議の再議は議決について行うもの）。イ：2の欄が経費を削る・減らす議決でなく、5の欄が「なお経費を削る・減らす議決をした」（177条1項）。ウ：3の欄が「示していない」で、2の欄が経費を削る・減らす議決でなく、5の欄が「再議・再選挙はまだ」以外（176条1項・176条4項。再議・再選挙は長が理由を示してさせるもの）。エ：8の欄に日数があり、3の欄が違反以外（176条5項）。オ：8の欄に日数があり、5の欄が「再議・再選挙はまだ」（176条5項）。カ：9の欄で裁定が出て、8の欄が空（176条6項。裁定は審査の申立てがあったときに出るもの）。キ：10の欄に日数があり、9の欄が「出ていない」（176条7項）。ク：12の欄が「していない」で、17の欄に日数がある（178条1項前段）。ケ：7の欄が6の欄より多い（5の欄が「再議・再選挙はまだ」なら見ません）。コ：14の欄が13の欄より多い。サ：15の欄が14の欄より多い（コ・サは12の欄が「していない」なら見ません）。ケ・コ・サは数のぶつかりで、条文の定めではないので条を付けず、論理の木に欄の番号を書きます。2つ以上の組が重なれば、全部出します。

特別区について：ここの条の語は「普通地方公共団体」「市町村長」で、特別区に直接触れていません。第283条1項の原文は次のとおりです。特別区の長がこのページの答えをそのまま使えるかは書いていません。

第二百八十三条（市に関する規定の適用）第1項　この法律又は政令で特別の定めをするものを除くほか、第二編及び第四編中市に関する規定は、特別区にこれを適用する。

地方自治法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。使っている条のマスを押すと原文が出ます。

アプリの約束事（地方自治法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • ①第176条第1項「異議があるとき」・第4項「違反すると認めるとき」・第179条第1項「長において…明らかであると認めるとき」は、どれも長の認識が要件なので、このアプリは議決が本当に違法か・本当に緊急かを判定しない。判定ページでは、3の欄で長が示した理由を、19の欄で長が判断したことを、事実として選んでもらう。第180条第1項の「軽易な事項」は聞かず、21の欄で議会が指定したかだけを聞く（下の (26)）
  • ②日数の数え方（初日を含むか）は条文に無いので、入れた日数のまま比べる
  • ③「当たりません」は、その条に当たらないと言うだけで、反対の結論を言うものではない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例・行政実例：条文だけを読むアプリのため
  • 会議規則：法律の条文でなく、議会ごとに定めるもののため
  • 第113条の中身：第179条第1項が指す先で、この範囲の外のため。会議を開くための出席は議員と議事のページで引けます
  • 第162条・第252条の20の2 の中身：第179条第1項ただし書が指す先で、この範囲の外のため。20の欄で同意を選ぶだけにした
  • 議員の除名など他の議決：この範囲の条の外のため。除名・懲罰は議員と議事のページで引けます
  • 地方公営企業など別の法律の再議：別の法律のため

条文だけで決まらなかった点（31点）：

  • （1）「三分の二以上」「四分の三以上」と端数 → 端数の語が無いので、割合を整数のまま掛けて比べ、要る人数は切り上げる（出席60人の3分の2は40人、出席27人の4分の3は21人、議員40人の3分の2は27人）
  • （2）特別区 → 条の語は「普通地方公共団体」「市町村長」で特別区に直接触れていないので、そのまま使えるかは書かず、上の範囲の節の第283条第1項の原文に留める
  • （3）第176条第1項の十日の起算 → 4の欄で、議決の日（条例・予算の議決は、長が送付を受けた日）からの日数を聞く。経費を削る・減らす議決も予算の議決として、送付を受けた日から数える。初日を含むかは語が無いので、入れた日数のまま比べる（約束事②）
  • （4）第177条第3項でみなされた不信任の議決と第178条 → 第178条第3項の「議員数の三分の二以上」「四分の三以上」や第178条第2項の「解散後初めて招集された議会」がどう当たるかは、第177条第3項にも第178条にも書いていない。第177条第3項の答えから不信任の小見出しへはつながず、12の欄で不信任の議決をしたかを別に聞く
  • （5）第176条第1項の「この法律に特別の定めがあるものを除くほか」と第177条 → 第177条が特別の定めに当たるかの語が無いので、2の欄で経費を削る・減らす議決を選び、3の欄で「議決に異議がある」を選んだら、第176条第1項と第177条第1項の両方の条を当てる
  • （6）第176条第2項で前と違う議決 → 確定の語が無いので「176条2項の確定に当たりません」とだけ出す。「中身を変えたが、なお経費を削る・減らす議決」も、前と同じ議決ではないとする
  • （7）第176条第4項の「再議に付し又は再選挙を行わせ」 → 2の欄で議決と選挙を分け、議決なら再議、選挙なら再選挙と出す
  • （8）第176条第5項の「なお…違反すると認めるとき」 → 長が審査を申し立てたこと自体が、なお違反と認めたことを示すと読み、8の欄の日数で受ける
  • （9）第176条第6項・第7項の「前項の裁定」 → 第6項の語は「取り消す旨の裁定をすることができる」だが、第8項は「議会の議決又は選挙の取消しを求める」訴えを書き、議決が取り消されていない場面で長が訴えることを前提にしていると読む。9の欄を「取り消す裁定」「取り消さない裁定」の3択にし、どちらでも第7項の訴えを出す。審査の結果の中身は読まない
  • （10）第176条第7項の「議会又は長」 → どちらが訴えるかは欄で分けず、「議会または長」と出す
  • （11）第176条第8項以外の訴えの被告 → 語が無いので、裁定の取消しを求める訴えは「議会を被告にする訴えに当たりません」とだけ出す
  • （12）第177条第1項の再議の期限 → 十日の語が無いので、期限を出さない。4の欄は3の欄が「議決に異議がある」のときだけ見る
  • （13）第177条の再議のあとの賛成の割合 → 語が無いので、6・7の欄は第176条第3項のときだけ見る
  • （14）第177条第2項・第3項の「なお…削除し又は減額したとき」 → 5の欄の「前と同じ議決・選挙をした」「中身を変えたが、なお経費を削る・減らす議決をした」が当たると読み、「前と違う議決・選挙をした」は経費を削っていない議決と読む。第177条に確定の語は無いので、確定とは出さない
  • （15）第178条第3項の「議員数」と「その四分の三以上」「その過半数」の「その」 → 「議員数」は今いる議員の数、「その」は出席した者を指すと読む。西宮市議会「市議会のしくみ」（2026年11月25日に取得）は「市長の不信任議決や議員の除名議決を行う場合などには、在職議員数の3分の2以上の出席が必要となります」と書く
  • （16）通知から十日を過ぎて解散した → 「前項の期間内に議会を解散しないとき」に当たると読み、期間が過ぎた日に職を失うと出す
  • （17）第178条第1項前段の通知 → 不信任の議決が成り立つときだけ出す。解散のあとの再びの不信任の議決にも出す
  • （18）再びの不信任のあとの解散 → 第178条第2項どおり、議長から通知があった日に職を失うと出し、解散を聞かない
  • （19）「解散後初めて招集された議会」か → 語の当てはめはしないで、12の欄の選択肢で事実として聞く
  • （20）第179条第1項ただし書と4つの場面 → ただし書はどの場面にもかかると読み、4つのどれでも「処分できません」と出す
  • （21）第179条第2項の「前項の例による」とただし書 → 選任の同意は議決すべき事件だが、20の欄で同意を選べば、18の欄に関わらずただし書を当てる
  • （22）第179条第3項で承認されなかったときの処分の効力 → 語が無いので出さない
  • （23）第179条第4項の措置の中身 → 語は「必要と認める措置」だけなので、中身を出さない
  • （24）第180条第2項の報告 → 語は「報告」で承認の語が無いので、承認とは出さない。議会が指定した専決処分も承認が必要と読める解説もある（野洲市議会「議会用語集」（2026年11月25日に取得）は「このほか、議会の議決によりあらかじめ指定した専決処分もあります。」に続けて「専決処分をしたときは議会に報告し、承認が必要です。」と書く）が、第180条第2項の語は報告だけ。鏡野町議会「議会用語集」（2026年11月25日に取得）は「専決処分をしたときは、次の議会においてこれを報告し、議会の委任に基づいて行った場合を除いては、議会の承認を求めることになっています。」と書き、同じ読み
  • （25）第179条と第180条が重なるとき → 語が無いので、19の欄で4つの場面のどれかを選び、21の欄で指定しているなら、両方の条を当てる
  • （26）第180条第1項の「軽易な事項」 → 軽易かは議会が指定するときに見るものと読み、聞かない。21の欄で議会が議決で指定したかだけを聞く
  • （27）第179条第1項の「長において…明らかであると認めるとき」 → 要件が長の判断そのものなので、19の欄の選択肢「緊急で議会を招集する時間が無いのが明らかだと、長が判断した」で事実として聞き、緊急かどうかを利用者に評価させない（約束事①）
  • （28）19の欄が「開ける」・21の欄が「指定していない」で、22の欄で処分した → 第179条第1項の4つの場面のどれでもないので「処分できません」と出す。法に反する処分も起きうる事実なので、「この組み合わせはありません」にはしない
  • （29）数字の欄が空 → 4・8・10・17の欄は「まだ付していない」「申し立てていない」「起こしていない」「通知はまだ」と読み、期限だけを出す。6・7の欄が空なら確定するかを、13〜15の欄のどれかが空なら不信任の答えを出さない
  • （30）期限を過ぎた後の段 → 4の欄が10日を超えたら第176条第2項・第3項の答えを、8の欄が21日を超えたら第176条第6項〜第8項の答えを、10の欄が60日を超えたら第176条第8項の答えを出さない
  • （31）数のぶつかり（賛成が出席より多い・出席が議員数より多い）→ 条文の定めではないので、条を付けずに「この組み合わせはありません」とし、論理の木に欄の番号を書く（上のケ・コ・サ）
