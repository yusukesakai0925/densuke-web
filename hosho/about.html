収録範囲・仕組み

「保証の効力と求償を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法の本則のうち、第446条・第448条・第452〜455条・第457条・第458条の2・第458条の3・第459条・第459条の2・第460条・第462条・第463条・第465条の2・第465条の3・第465条の4・第465条の6・第465条の9・第465条の10をルールにしています。

入力の欄は、起きた事実を聞く32個で、いつも全部を出します。同じ入力でこれらの条を全部当てるので、例えば「頼まれた保証人が、弁済期前に払った」を選ぶと、どの限度で求償権を持つか（第459条の2第1項）と、いつ行使できるか（第459条の2第3項）の判定が並んで出ます。前の欄の答えで意味を持たない欄（例：根保証でないのに選んだ7の欄、まだ払っていないのに選んだ30〜32の欄）は、答えに使いません。事実として成り立たない組は「この組み合わせはありません」と、欄の番号と根拠条を出します（選択肢の言葉どうしでぶつかるだけの組は、条を付けず欄の番号だけを出します）。裁判所などでどうなるかを当てる道具ではなく、入力のとおりなら条文がどう定めているかを確かめるものです。個別のことは法律の専門家に聞いてください。

入っていないもの：下の載せなかったものをご覧ください。

判定について：

  • 当てはめは判定しません。「事業のために負担した」「資力」「執行が容易」「過失なく」「善意」「債権者が知ることができた」「誤認」に当たるかは、事情で決まり、条文だけでは決まりません。本人がそう考えているかを入力にしているだけです。根保証で債務の一部だけが事業の貸金等のときの範囲も、条文だけでは決まりません。
  • 条文だけを読んでいます。判例の読み方（催告の抗弁・検索の抗弁を放棄する特約、連帯保証人の求償の範囲 など）は載せません。
  • 特約の効力は判定しません。保証契約に当事者の約束（特約）があっても、それが条文の定めを変えられるかは条文からだけでは決まらないので、答えは条文の定めのとおりに出します。特約が効かないと言うものではありません。
  • 債務を守らなかったときの賠償・解除は債務不履行と解除のページで引いてください。
  • 語の言い換え：主たる債務者＝保証してもらった債務を負う人。根保証＝一定の範囲に属する不特定の債務の保証。極度額＝根保証で保証人が負う上限の額。元本確定期日＝根保証で保証する元本が確定する日。債務の消滅行為＝主たる債務者に代わって弁済などをして債務を消滅させること。求償権＝払った保証人が主たる債務者に返してもらう権利。これらは条文の語をこのアプリが言い換えたものです。
民法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（民法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは、欠けた要件が分かる起きた事実の文か「当たりません」とだけ出し、反対の結論（ほかの理由で効力を生じる・請求できる等）は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例の基準：条文だけを読むアプリのため
  • 金額・日付の計算：条文は「その消滅した額」「三年を経過する日」までで、計算の語が無いため
  • 特約の効力：どこまで変えられるかが範囲の条の語に無いため
  • 第447条・第449〜451条・第456条・第458条・第461条・第464条・第465条・第465条の5・第465条の7・第465条の8の中身：今回の問いの外のため
  • 第465条の6第2項の方式の中身：公正証書の作り方で、効力の入力に置かないため。項の文だけを残す
  • 第427条・第436〜445条（連帯債務）の中身：引き先のため
  • 貸金業法・借地借家法・消費者契約法との関係：別の法律のため

条文だけで決まらなかった点（22点）：

  • （a）保証契約が効力を生じない組（446条2項・465条の2第2項3項・465条の6第1項） → 元本確定期日（465条の3）・取消し（465条の10）・請求されたとき・払う前と払った後の条は、保証契約が効力を持つことが前提なので、答えを出さない
  • （b）462条1項は459条の2第1項を準用するが、459条の2の見出しは「弁済期前」で、準用の文に弁済期の限定が無い → 委託を受けず意思に反しない保証人は、弁済期の前後を問わず「その当時利益を受けた限度」と書かれたとおりに出す
  • （c）465条の2第2項は「極度額を定めなければ」と書き、446条2項は保証契約そのものの方式を書く。極度額だけ書面にないとき → 465条の2第3項の準用で効力を生じないと読む
  • （d）根保証で債務の一部だけが事業の貸金等のときの範囲は条文で決まらない → 6の欄で「事業のための貸金等債務が含まれる」を選んだときだけ465条の6を当てる
  • （e）453条の「催告をした後であっても」 → 催告の後も含めるという語で、催告の前を除く語は無いので、催告の前後を分けずに当てる（前の版は催告の後だけ当てていた）
  • （f）455条の「請求又は証明」がどちらか・「催告又は執行」がどちらか → 語は「又は」なので1つの欄で聞く
  • （g）454条は「前二条の権利を有しない」で、455条の語は無い → 連帯のときは455条の答えを出さない
  • （h）465条の2第3項の準用で、電磁的記録も書面と同じか → 446条3項も準用されているので、1つの欄で聞く
  • （i）465条の3第3項（変更）と第4項（元本確定期日の定めの方式） → 入力に置かず聞かない
  • （j）465条の3で、期日が締結の日から五年以内のとき → 語は第1項の「後の日と定められているとき」だけなので、それに当たらないと出す（定めが効力を持つとは言わない）
  • （k）「保証人」「保証人になろうとする者」「保証をする者」 → 関係の語が無いが、1つの欄で聞く。法人の根保証は、465条の2〜465条の4の「個人根保証契約」に当たらないと出す
  • （l）465条の9の「前三条」に465条の10は入らない → 語のとおり、9の欄の答えは465条の10の段に効かせない
  • （m）465条の6の「事業のために負担した貸金等債務」と465条の10の「事業のために負担する債務」 → 語が違うので、6の欄の選択肢で分ける
  • （n）465条の10第2項の「情報を提供せず」と「事実と異なる情報」が両方あるとき → 語が無いので、どれか1つを選ぶ欄にした
  • （o）465条の4の事由が複数あるとき → 18・25・26の欄で別に聞き、当たる号を全部出す。18の欄と26の欄の中では1つを選ぶ
  • （p）448条1項と2項の両方に当たるとき、457条2項と3項の両方に当たるとき → 順番の語が無いので、別の段で並べる
  • （q）458条の3の「二箇月以内に通知」で、過ぎてから通知したときと通知していないとき → 語は「期間内に通知をしなかったとき」で同じなので、1つの選択肢にする
  • （r）459条の2第1項・462条2項・463条1項の後ろの文（相殺）・460条第2号ただし書 → 入力に置かず聞かない。原文を開けば読める
  • （s）463条3項は「意思に反して保証をしたときのほか」 → 意思に反するときは通知の有無を見ない
  • （t）前の欄の答えで意味を持たない欄 → 答えに使わない（例：根保証でないのに選んだ7・8の欄、事業のための貸金等債務でないのに選んだ9・10の欄、まだ払っていないのに選んだ30〜32の欄、払った後に選んだ28・29の欄）。事実として成り立たない組（5と6、17と19と20、31と32の欄）は、この組み合わせはありませんと出す
  • （u）460条の「あらかじめ」 → 保証人がまだ債務の消滅行為をしていないときだけ読む。当たる号は全部出す
  • （v）条に当たらない文を出す場面 → 欄で起きたことを選んだが、条の別の要件が欠けるときだけ出す。何も起きていない欄（していない・ない）の条は出さない
