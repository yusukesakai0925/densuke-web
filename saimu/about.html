収録範囲・仕組み

「債務不履行と解除を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法の本則のうち、第412条・第412条の2・第413条の2・第415条・第416条・第418条〜第421条・第540条〜第548条をルールにしています。

入力の欄は、起きた事実を聞く27個で、いつも全部を出します。同じ入力で第412条〜第421条・第540条〜第548条を全部当てるので、例えば「全部が、もう果たせない」を選ぶと、履行を請求できるか（第412条の2）、損害の賠償を請求できるか（第415条）、解除できるか（第542条）の判定が並んで出ます。前の欄の答えで意味を持たない欄（例：確定期限なのに選んだ2の欄、お金の約束ではないのに選んだ不可抗力の欄）は、答えに使いません。事実として成り立たない組は「この組み合わせはありません」と、欄の番号と根拠条を出します。裁判所などでどうなるかを当てる道具ではなく、入力のとおりなら条文がどう定めているかを確かめるものです。個別のことは法律の専門家に聞いてください。

入っていないもの：下の載せなかったものをご覧ください。契約の取消しは意思表示のページで引いてください。賠償の請求権が時効で消えるかと、不法行為は、このページでは扱いません。

判定について：

  • 当てはめは判定しません。「債務者の責めに帰することができない事由」「不可抗力」「軽微」「相当の期間」「通常生ずべき損害」「特別の事情」「予見すべきであった」「契約をした目的を達することができない」「見込みがないことが明らか」「債権者の責めに帰すべき事由」「過失」「故意若しくは過失」に当たるかは、事情で決まり、条文だけでは決まりません。本人がそう考えているかを入力にしているだけです。損害の額や利息の額は計算しません。
  • 条文だけを読んでいます。判例の読み方は載せません。
  • 契約の取消しは意思表示のページで引いてください。賠償の請求権が時効で消えるかと、不法行為は、このページでは扱いません。
  • 重なりは並べて出します。同じ入力で2つ以上の条が当たるときは、どれの判定も出します。どれが優先するかの語は条文に無いので、出しません。ただし、賠償の額を前もって約束していたとき（違約金を含む）は、第416条・第418条・第419条の答えを出しません。第544条2項・第547条・第548条で解除権が消滅したときは、解除できるという答えを出しません。
  • 語の言い換え：債務＝約束したことを果たす義務。債務者＝果たす側。債権者＝果たしてもらう側。履行＝果たすこと。不能＝もう果たせないこと。遅滞の責任＝遅れたことの責任。責めに帰すべき事由＝その人のせい。当事者双方の責めに帰することができない事由＝どちらのせいでもない事由。催告＝期間を決めて、果たすよう求めること。軽微＝わずか。確答すべき旨の催告＝期間を決めて、解除するかどうか答えるよう求めること。これらは条文の語をこのアプリが言い換えたものです。
民法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（民法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは「当たりません」とだけ出し、反対の結論（ほかの理由で請求できる・解除できる等）は出さない
  • 条文の語だけでは決まらない入力には「決まりません」と出し、どちらかに寄せない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例の基準：条文だけを読むアプリのため
  • 損害額の計算：条文に計算の語が無く、額は裁判所が定めるため
  • 法定利率の数字（第404条）：第419条1項が指す先で、範囲の外のため
  • 第413条（受領遅滞の保存義務・費用）：今回の問いが賠償と解除で、保存の義務と費用の負担は別の話のため
  • 第414条（履行の強制）：裁判所に請求する手続の話で、今回の問いの外のため
  • 第417条・第417条の2：賠償の方法と中間利息の話で、額の計算に入るため
  • 第422条・第422条の2：賠償の後の代位と代償請求の話で、範囲の外のため
  • 第533条の中身：第546条の準用先のため。準用すると書いた第546条の原文だけを出す
  • 売買の契約不適合（第562条以下）：売買だけの定めで、範囲の外のため
  • 約款・消費者契約法との関係：別の条・別の法律のため
  • 不法行為との関係：条文に語が無いため。不法行為のページへのリンクだけを置く

条文だけで決まらなかった点（26点）：

  • （a）419条3項の「不可抗力」と415条1項ただし書の「責めに帰することができない事由」 → 419条3項は「不可抗力」としか書いていないが、不可抗力すら抗弁にならないので、それより弱い「責めに帰することができない事由」も抗弁にならない、と読むのが一般的な解説である。お金の約束では、債務者のせいとはいえない事由によるときも、不可抗力のときと同じく賠償を請求できると出す
  • （b）415条2項3号の「解除権が発生したとき」と543条 → 543条で解除できないときに当たるか書かれていないので、1号・2号にも当たらなければ「決まりません」と出す
  • （c）541条の催告をしたのに542条の号にも当たるとき → どちらの根拠も並べ、「催告をすることなく」の答えを出す
  • （d）遅滞の責任を負う前に、どちらのせいでもない事由で不能となったとき → 413条の2第1項には当たらないと出し、債務者の責めに帰することができない事由によるものとして415条1項ただし書で読む
  • （e）413条の2第2項の「債権者の責めに帰すべき事由」と415条1項ただし書・543条 → 当事者双方の責めに帰することができない事由なので、賠償は「415条1項本文の定めは当てはまりません」と出し、解除は543条で「できません」と出す
  • （f）遅滞中で、かつ履行の提供があった時以後の不能が重なるとき → 語が無いので、どちらか1つを選ぶ欄にした
  • （g）412条2項の「いずれか早い時」で2つが同じ時のとき → どちらの時でも同じ時なので、どちらか1つを選ぶ欄にした
  • （h）お金の約束に416条の範囲を出すか → 419条に416条を除く語が無いので、両方の答えを出す
  • （i）420条の賠償額の予定と416条・418条・419条の関係 → 語が無い。予定の効力は判定せず、予定が効かないと読める答えを出さないために、賠償の額を約束していたときは416条・418条・419条の答えを出さない
  • （j）412条の2第2項のときの412条の2第1項 → 第1項の語は「不能であるとき」で成立の時を除かないので、履行を請求できないと両方出す
  • （k）421条の「前条の規定」 → どの項かは書かれていないので、「420条の規定が準用されます」とだけ出す
  • （l）542条1項5号の「前各号に掲げる場合のほか」 → 1〜4号のどれかに当たるときは、17の欄は答えに使わない
  • （m）542条1項3号と2項が重なるとき → 3号に当たれば全部の解除として出し、2項は出さない
  • （n）541条の「相手方」と542条の「債権者」 → 語が違うが、解除する側を「債権者」にまとめて出す
  • （o）540条1項の「契約又は法律の規定」 → 契約で定めた解除権は聞かず、解除できるかは541条・542条だけで出す
  • （p）544条の「全員から又は全員に対して」と消滅の理由 → どちらの側かを分けず欄を1つにし、消滅の理由も聞かない
  • （q）545条の行使と547条・548条の消滅 → 順番の語が無いので、別の段で並べる。548条の欄は解除すると伝える前のこととして聞く。547条・548条で消滅したときは、解除できるという答えを出さない
  • （r）545条2項の利息の率 → 語が無いので「利息を付さなければなりません」までを出す
  • （s）548条の「故意若しくは過失」と「加工若しくは改造」 → 加工改造には故意過失の語がかかる形に読めないので聞かない。ただし書は3つすべてにかかると読む
  • （t）「この限りでない」 → 415条1項・541条・548条のただし書で、「本文の定めは当てはまりません」と出す
  • （u）遅滞の責任を負う前の「債務の本旨に従った履行をしない」 → 期限がまだ来ていない（期限を決めていなければ請求されていない）のに、不能でも拒絶でもなく「果たしていない」を選んだときは、まだ不履行は起きていないと読み、この組み合わせはありませんと出す
  • （v）一部の不能と412条の2第1項・415条2項1号 → 一部の不能も「履行が不能であるとき」に当たると読み、412条の2第1項は不能な一部について履行を請求できないと出す
  • （w）一部の拒絶と415条2項2号 → 一部でも「履行を拒絶する意思を明確に表示したとき」に当たると読む
  • （x）415条2項3号の「その契約が解除され」「解除権が発生した」 → 欄で聞かず、同じ入力の解除の答え（541条・542条で解除権が発生したか）と21の欄から出す。544条2項・547条・548条で後から消滅しても、「発生した」には当たると読む。544条1項の「全員から又は全員に対して」は解除のしかたの定めなので、全員からでないときも「発生した」に当たると読む
  • （y）545条の「解除権を行使したとき」と解除権の有無 → 541条・542条で解除権が発生していない、又は消滅しているのに「解除すると伝えた」を選んだときは、545条1項本文に当たらないと出し、545条・546条のほかの答えは出さない
  • （z）前の欄の答えで意味を持たない欄 → 答えに使わない（例：確定期限なのに選んだ2の欄、お金の約束ではないのに選んだ不可抗力の欄、数人でないのに選んだ20の欄）。事実として成り立たない組（1と2、1と2と3と4、3と5、5と18、21と25の欄）は、この組み合わせはありませんと根拠条つきで出す
