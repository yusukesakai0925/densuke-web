1. MCPとは何か

MCP = Model Context Protocol。AIと外部のサービス・データをつなぐための、差込口の形を統一した取り決めです。

公式ドキュメントはこう説明しています（原文ママ）。

"USB-C port for AI applications. Just as USB-C provides a standardized way to connect electronic devices, MCP provides a standardized way to connect AI applications to external systems."
出典: https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro （旧URL /introduction からの転送先。仕様バージョン 2026-07-28）

従来はAIごと・サービスごとに個別の配線が必要でしたが、差込口の形が統一されたので、一度作れば対応する複数のAI（Claude／ChatGPT／VS Code／Cursor 等）から同じように使えます。

用語（この3つだけ押さえれば読めます）

語意味
MCPサーバーデータや機能を提供する側（例: サイトの中身を返す）
MCPクライアントAI側（Claude など）
ツールAIが呼べる命令のこと。MCPサーバーが「こういう命令が使えます」と一覧を返し、AIがそれを選んで呼ぶ

つなぎ方は2種類

stdio: newline-delimited messages over the standard streams of a client-launched subprocess.
Streamable HTTP: each message is an HTTP POST to a single MCP endpoint; replies arrive as a JSON object or a request-scoped SSE stream.
出典: https://modelcontextprotocol.io/specification/2026-07-28/basic/transports

要するに ①同じPCの中で起動して繋ぐ（stdio） と ②URLで繋ぐ（Streamable HTTP）。Cloudflareの公式サーバーは全部②です。

学ぶときの注意：ネット上の解説記事には古い「HTTP+SSE」方式の手順が大量に残っています。

"Streamable HTTP was introduced in protocol version 2025-03-26 as a replacement for the HTTP+SSE transport from protocol version 2024-11-05."
"The HTTP+SSE transport from protocol version 2024-11-05 has been deprecated since protocol version 2025-03-26 and is classified as Deprecated under the feature lifecycle policy."
出典: https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http

エンドポイントの形（原文ママ）：The server MUST provide a single HTTP endpoint path (hereafter referred to as the MCP endpoint) that supports POST. For example, this could be a URL like https://example.com/mcp。URLの末尾が /mcp なのはこのためです。

docsサーバーが公開しているツールは2つ（原文ママ）：

  • search_cloudflare_documentation : Search the Cloudflare documentation.
  • migrate_pages_to_workers_guide : ALWAYS read this guide before migrating Pages projects to Workers.

つまり「認証不要で今すぐ試せるサーバー」と「Cloudflareアカウントのログインが要るサーバー」の2種類があります。学習の入口は前者です。

実際にAIにつなぐときの設定（原文ママ）

{ "mcpServers": { "cloudflare-api": { "url": "https://mcp.cloudflare.com/mcp" } } }

出典: https://developers.cloudflare.com/agents/model-context-protocol/cloudflare/servers-for-cloudflare/ （Last updated Jul 28, 2026）／同ページ: "When you connect, you will be redirected to Cloudflare to authorize via OAuth and select the permissions to grant to your agent."

この url を https://docs.mcp.cloudflare.com/mcp に変えれば、ログイン画面すら出ずに繋がります（上の実測どおり）。
