収録範囲・仕組み

「事務管理と不当利得を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法の本則のうち、第697条〜第708条と、準用先の第645条〜第647条・第650条第2項をルールにしています。

頼まれずに他人の用事をしたこと、理由なく利益を受けたこと、物やお金を渡したことについて起きた事実の21個の欄から、第697条〜第708条を同じ入力で全部当てます。どの条の話かを先に選ぶ欄は置いていません。人は、管理をした・渡した・損失を受けた側を「Aさん」、管理をしてもらった・受け取った・利益を受けた側を「Bさん」と書きます。第707条の債務者は「Aさんでない債務者」と書きます。

入っていないもの：下の載せなかったものをご覧ください。不法行為の損害賠償は不法行為のページで、委任は請負と委任のページで、時効は時効のページで、債務不履行と解除は債務不履行のページで引いてください。無効・取消しの後の原状回復は範囲の外です。

判定について：

  • 当てはめは判定しません。「他人のために」「有益」「本人の意思に反し」「本人に不利であることが明らか」「急迫の危害」「重大な過失」「法律上の原因」「そのために（利益と損失のつながり）」「利益の存する限度」「悪意」「錯誤」「善意」「不法な原因」は、裁判所が決める評価です。本人の答えを入力にしているだけです。
  • 条文だけを読んでいます。判例は載せません。第701条の準用で受任者を管理者（Aさん）、委任者を本人（Bさん）と読み替えるのと、第650条第2項の「必要と認められる債務」を「有益な債務」と読むのは、下の（c）（d）の読みです。
  • 金額・利息は計算しません。第703条の「利益の存する限度」は、受けた利益が全部残っているか・一部だけ残っているか・残っていないかだけを聞いています。第699条の「遅滞なく」かどうかも判定しません。
  • 第702条第1項・第2項に報酬の語はありません。報酬を聞く欄は置かず、判定の結果にも出しません（下の（e））。
  • 関係のない欄（たとえば、1の欄が「していない」のときの2〜9の欄、15の欄が「渡していない」のときの16〜21の欄）は、答えを出さないだけです。この本には「この組み合わせはありません」になる組がありません（片方の値でもう片方を聞くかが決まる6組を、1つの欄にまとめたため）。1・10・15の欄がどれも「無い」側のときは、当てる条がありませんと答えます。
民法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。第650条は第2項だけをルールに使っていますが、マスを押すと条の全部が出ます。

アプリの約束事（民法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは、欠けた要件が分かる起きた事実の文だけを出し、反対の結論は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例の基準（三者の間の不当利得、転用物、騙取金など）：条文だけを読むアプリのため
  • 金額・利息の計算：入力ははい・いいえで受け、条文は「利益の存する限度」「利息を付して」までのため
  • 第三者の弁済の第474条・弁済の中身：範囲の外のため
  • 不法行為の中身：不法行為のページで引くため
  • 時効の中身：時効のページで引くため
  • 刑法・特別法（貸金業法など）：別の法律のため
  • 無効・取消しの後の原状回復の第121条の2：範囲の外のため

条文だけで決まらなかった点（23点）：

  • （a）698条は「悪意又は重大な過失があるのでなければ…責任を負わない」と書くが、悪意又は重大な過失があるときに何の責任を負うかは書いていない → 「698条によっては、事務管理によって生じた損害を賠償する責任を免れません」とだけ出し、賠償の中身は言わない。これは読みです
  • （b）697条2項の「本人の意思」と702条3項の「本人の意思に反して」の関係（知らなかった意思に反した場合を含むか）は語だけで言い切れない → 2の欄と9の欄で別々に聞き、関係は言わない。これは読みです
  • （c）701条は645条〜647条を準用するが、語の読み替えを書いていない → 受任者を管理者（Aさん）、委任者を本人（Bさん）、委任事務を事務管理と読み替えて出し、論理の木に原文も並べる。これは読みです
  • （d）702条2項が準用する650条2項は「必要と認められる債務」の文で、702条2項は「有益な債務」 → 「有益な債務を負担した場合」と読み、論理の木に原文も並べる。これは読みです
  • （e）702条1項・2項には報酬の語が無い → 報酬を聞く欄を置かず、判定の結果にも出さない（このページの「判定について」にだけ書く）。これは読みです
  • （f）704条の「その受けた利益」が、703条の「利益の存する限度」を超えて全部を指すのかは704条が言い切っていない → 悪意の受益者には語のとおり「受けた利益に利息を付して」と出し、限度との関係は言わない。13の欄（受けた利益が残っているか）は善意の受益者のときだけ使う。これは読みです
  • （g）705条は「返還を請求することができない」とだけ書き、703条との関係を書いていない → 705条に当たれば「請求することができません」と出す。11の欄が「ある」でBさんが703条の受益者に当たらないときは、703条の答えと705条の答えを、主語と根拠条を立てて別の行に出す。これは読みです
  • （h）708条ただし書は「受益者についてのみ」と書く。不法な原因が両方にあり、程度に差がある場合は書いていない → 「Aさんにもあった」の入力は本文どおり「請求することができません」と出し、程度の比較はしない。これは読みです
  • （i）699条は通知しないときにどうなるかを書いていない → 遅滞なく通知しなければならないことまでを答え、通知したかどうかで答えは変えない。これは読みです
  • （j）700条本文の「至るまで」の後に何が残るかの語は無い → 「700条によっては、事務管理を継続する義務を負いません」と出すまでにする。これは読みです
  • （k）650条2項で債務が弁済期にないとき、前段の弁済の請求もできるかの語は無い → 「この場合において」なので前段と後段を並べて出す（請負と委任のページと同じ）。これは読みです
  • （l）705条は債務が存在しない話で、706条・707条は債務がある話 → 16の欄（弁済として渡した債務は）1つにまとめて聞き、705条・706条・707条を分ける。債務が存在するのに、存在しないことを知っていた、という入力は置かない。これはこのアプリの作りです
  • （m）707条1項の「善意で」が、証書・担保の行為だけにかかるのか「時効によってその債権を失った」にもかかるのかは語だけで言い切れない。何についての善意かも書いていない → 19の欄の「善意」を、20の欄の3つの行為すべてに当てる。これは読みです
  • （n）債務の弁済として給付したものが不法な原因のためでもある場合の、705条〜707条と708条の関係は書いていない → 15の欄で給付を1つ選ぶ入力にして、両方を同時に聞かない。これは読みです
  • （o）700条ただし書の「明らかであるとき」が「本人の意思に反し」にもかかるのかは語だけで言い切れない → どちらも「明らか」として聞く。これは読みです
  • （p）707条2項の「前項の規定は」は、707条1項に当たらないときの求償権を言っていない → 707条1項に当たるときだけ出す。これは読みです
  • （q）706条ただし書の「得た利益」を返すときに、本文の「請求することができない」が残るかは語だけで言い切れない → 本文の答えと、ただし書の答えを別の段で並べる。これは読みです
  • （r）704条後段の「その賠償の責任」と、698条・647条の賠償が、不法行為の損害賠償とどう関係するかは書いていない → 語のとおりに出し、関係は言わない。これは読みです
  • （s）705条〜708条は703条との関係を書いていない。同じ給付について、703条・704条の「返還する義務を負います」と705条〜708条の「返還を請求することができません」を並べると、同じ2人について両方に読める → 705条〜708条で給付したものの返還を請求することができないときは、703条・704条の返す範囲となお損害の答えを出さない。これは読みです
  • （t）1・10・15の欄がどれも「無い」側のときは、当てる条がない → 697条1項と703条の答えを2つ出す形にせず、「…のどれも起きていないので、当てる条がありません」と1つだけ答える。これはこのアプリの作りです
  • （u）同じ出来事から事務管理（702条の費用の償還など）と不当利得（703条）の両方が問われるとき、事務管理が703条の「法律上の原因」になるかを条文は書いていない → 両方の答えを並べるだけで、関係は言わない。これは読みです
  • （v）事務管理の本人と707条の債務者が別の人になる組は、条文上ありえない組ではない → 「この組み合わせはありません」にせず、Bさん（本人・債権者）と「Aさんでない債務者」を別の人として並べる。これは読みです
  • （w）704条後段は「この場合において」と書き、悪意の受益者の話 → 善意の受益者でなお損害があるときは「704条後段によっては、損害を賠償する責任を負いません」と出し、不法行為など別の根拠は言わない。これは読みです
