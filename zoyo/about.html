収録範囲・仕組み

「贈与を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法（明治二十九年法律第八十九号）の本則のうち、第三編 債権 第二章 契約 第二節 贈与の第549条〜第554条を、全部ルールにしています。

入力の欄は、起きた事実を聞く7個で、いつも全部を出します。同じ入力で第549条〜第554条を全部当てるので、例えば「毎月の仕送りの約束で、あげる人が亡くなった」と「口約束で、まだ渡していない」を両方選ぶと、第552条と第550条の両方の判定が出ます。前の欄の答えで意味を持たない欄（例：もらう人がまだ受け入れていないのに選んだ書面の欄）は、答えに使いません。裁判所などでどうなるかを当てる道具ではなく、入力のとおりなら条文がどう定めているかを確かめるものです。個別のことは法律の専門家に聞いてください。

この XML は2026年11月4日に取得した版（定型約款の Prolog と同じファイル）で、それ以後の改正と、公布済みで施行前の改正は読んでいません。

判定ページでは原文をそのまま並べ、その横にこのアプリの言い換えを置いています。原文は直していません。

売買（担保の責任）・双務契約・遺贈の条文、贈与税（相続税法）、判例は読んでいません。売買は別のページ（売買の契約不適合を逆から引く）、遺言と遺贈は別のページ（遺言と遺留分を逆から引く）で扱っています。

附則は読んでいません。

入っていないもの：下の載せなかったものをご覧ください。

判定について：

  • 当てはめは判定しません。何が「書面」に当たるか、渡し終えたか（履行が終わったか。たとえば不動産で、引渡しだけ、または登記だけが済んだとき）、受け入れた（受諾した）か、負担があるか、物・権利に問題があるか、定期の給付に当たるかは、事情で決まり、条文だけでは決まりません。本人がそう考えているかを入力にしているだけです。渡す物の値打ちと負担の大きさの金額は聞かず、計算しません。
  • 条文が先の定めに任せている中身は判定しません。担保の責任の中身（売買の定め）、第553条で準用される双務契約の規定がどれか（もらう人が負担を果たさないときに解除できるかなど）、第554条で準用される遺贈の規定がどれか（遺言と同じ書き方が要るか、後から取りやめられるかなど）、定期の贈与で亡くなる前にもう渡した分がどうなるかは、出しません。
  • 重なりは並べて出します。同じ入力で2つ以上の条が当たるとき（例：毎月の仕送りの約束であげる人が亡くなり、口約束で、まだ渡していない）は、どちらの判定も出します。どちらが優先するかの語は条文に無いので、出しません。
  • 贈与税（相続税法）は読んでいません。売買（売主の担保の責任）・双務契約・遺贈の条文と判例も読んでいません。売買は別のページ（売買の契約不適合を逆から引く）、遺言と遺贈は別のページ（遺言と遺留分を逆から引く）で扱っています。
  • 語の言い換え：贈与者＝あげる人。受贈者＝もらう人。受諾＝申し出を受け入れること。解除＝約束を一方からの申し出でやめること。書面によらない贈与＝約束を紙（書面）に書いていない贈与。履行の終わった部分＝もう渡し終えた部分。特定した時の状態＝あげる物がこれと決まった時の状態。推定する＝反対の約束を示せば覆る、という決め方。負担付贈与＝もらう人も何かをする約束（負担）のついた贈与（たとえば介護を条件に家をあげる約束）。担保の責任＝渡した物や権利に問題があったときに負う責任。定期の給付＝毎月・毎年など決まった時期にくり返し渡すこと。双務契約＝お互いに義務を負う契約。準用＝別の定めを、合うように読み替えて当てはめること。遺贈＝遺言で財産をあげること。死因贈与＝あげる人が亡くなった時に効力が生じる贈与。これらは条文の語をこのアプリが言い換えたものです。
この法律のどこまでをルールにしたか（全条文の地図）

民法の本則の全条文を、編・章ごとに1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条、斜線は削除された条です。マスを押すと原文が出ます。

アプリの約束事（この法律の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは「当たりません」とだけ出し、反対の結論（ほかの理由で解除できる・担保の責任を負わない等）は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 何が「書面」に当たるか・渡し終えたか（履行が終わったか）の当てはめ：事情で決まり、条文だけでは決まらないため判定しません
  • 担保の責任の中身：売買の定めで、読んでいないため判定しません。売買は別のページ（売買の契約不適合を逆から引く）
  • 第553条で当てはめる双務契約の規定がどれか（もらう人が負担を果たさないときに解除できるかなど）：条文だけでは決まらず、双務契約の条文は読んでいないため判定しません
  • 第554条で当てはめる遺贈の規定がどれか（遺言と同じ書き方が要るか、後から取りやめられるかなど）：条文だけでは決まらず、遺贈の条文は読んでいないため判定しません。遺言と遺贈は別のページ（遺言と遺留分を逆から引く）
  • 定期の贈与で、亡くなる前にもう渡した分：条文に書いてないため判定しません
  • 贈与税（相続税法）：別の法律で、読んでいないため判定しません
  • 判例・解説書：条文だけを読むアプリのため
  • 附則：本則の範囲だけを読むため

条文だけで決まらなかった点（20点）：

  • （1）第549条 → 「あげる」「もらう」の意思が両方そろったか、あげる側だけかは入力で選ばせ、受諾に当たるかの当てはめはしない
  • （2）第549条 → 書面も、物を渡すことも、成り立つための条件ではないと読む（条文は意思の表示と受諾だけを挙げている）。書面と渡したかの欄は第550条でだけ使う
  • （3）第549条で成り立たないとき → 第550条〜第554条は「贈与」を前提にするので、ほかの欄は答えに使わない
  • （4）第550条 → 書面があるか、渡し終えたかは入力で選ばせ、当てはめはしない
  • （5）第550条 → 解除するのが誰かは聞かない。条文は「各当事者」で、あげる人ともらう人で答えが変わらないため
  • （6）第550条ただし書の「部分」→ 一部だけ渡したときは、まだ渡していない部分は本文で解除でき、渡し終えた部分には本文の定めが当てはまらないと読み、2つの答えを並べる
  • （7）第550条ただし書の「この限りでない」→ 「本文の解除の定めは当てはまりません」と書き、ほかの理由で解除できるかは出さない
  • （8）書面があるとき → 「書面によらない贈与」に当たりませんとだけ出し、第550条のほかの理由で解除できるかは出さない
  • （9）第551条第1項の「推定する」→ 推定されますと書き、「傷があっても直して渡さなくてよい」とは断定しない
  • （10）第551条第1項 → 物・権利に問題があると選んだときだけ答えを出す（条文はどの贈与にも当たるが、問題が無ければ渡す状態を問う場面が無いと読んだ）。負担があるときも第1項で答える（第1項は負担付きに限らない）
  • （11）第551条第2項の「負担の限度」→ 「もらう人の負担の限度で」と書き、金額は計算しない
  • （12）第551条第2項 → 負担の無い贈与で物に問題があるときは「負担付贈与」に当たりませんとだけ出す
  • （13）第553条 → 負担があれば、双務契約の規定が準用されるとだけ出す。どの規定が当てはまるか（もらう人が負担を果たさないときに解除できるかなど）は条文だけでは決まらないので出さず、双務契約の条番号も足さない。負担を果たしたかは聞かない（第553条の答えが変わらないため）
  • （14）第552条 → 亡くなる前にもう渡した分は判定しない。相続人がどうなるかは書かない。効力を失うときは第550条（本文・ただし書）の答えを出さない
  • （15）第552条 → 誰も亡くなっていないときは答えを出さない（「効力を失わない」とも書かない）
  • （16）第552条の「定期の給付」→ 「毎月・毎年など、決まった時期にくり返し渡す」と言い換え、当てはめはしない
  • （17）第554条 → 死んだらあげる約束のときは、誰が亡くなったかで答えを分けない（誰が先に亡くなったかで遺贈の規定のどれが当たるかは、遺贈の条文を読んでいないので分けられない）。どの遺贈の規定が当てはまるかは条文だけでは決まらないので出さない
  • （18）いつ渡す約束かの欄 → 「くり返し」「亡くなった時」「どちらでもない」を1つの欄で選ぶ。定期で、しかも亡くなった時から始まる約束は選べない
  • （19）語の開き方 → 「判定について」の語の言い換えと、条文ごとの言い換え（8行）は、このアプリの言葉
  • （20）贈与税・売買・双務契約・遺贈の条文・判例 → 読んでいないので判定しない
