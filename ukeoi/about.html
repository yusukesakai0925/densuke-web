収録範囲・仕組み

「請負と委任を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法の本則のうち、第632条〜第634条・第636条・第637条・第641条〜第656条と、準用先の第620条・第624条をルールにしています。

入力の欄は、起きた事実を聞く22個で、いつも全部を出します。1の欄（何を約束したか）が請負なら第632条〜第642条を、委任・法律行為でない事務の委託なら第643条〜第656条を、同じ入力で全部当てます。1の欄で選ばなかった方の欄は、選んでいても使いません。欄どうしで成り立たない組は「この組み合わせはありません」と根拠条を出します。実際の争いでどうなるかを当てる道具ではなく、入力のとおりなら条文がどう定めているかを確かめるものです。

入っていないもの：下の載せなかったものをご覧ください。売買の契約不適合、債務不履行と解除、時効、代理は、このページでは扱いません。

判定について：

  • 当たるかは判定しません。「責めに帰することができない事由」「可分」「利益を受ける」「契約の内容に適合しない」「重大な過失」「やむを得ない事由」「相手方に不利な時期」「受任者の利益」「急迫の事情」「必要と認められる」は裁判所が決める評価です。本人がそう考えているかを入力にしているだけです。ある契約が請負か委任かも、この画面では判定しません。
  • 条文だけを読んでいます。判例の読み方は載せません。
  • 売買の契約不適合、債務不履行と解除、時効、代理は、このページでは扱いません。
  • 第536条（危険負担）は範囲の外です。第634条第1号・第648条3項第1号・第648条の2第2項が準用する第634条第1号の「責めに帰することができない事由」に当たらないときは「当たりません」とだけ出し、第536条の中身は出しません。
民法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（民法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは「当たりません」とだけ出し、反対の結論は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例の基準：条文だけを読むアプリのため
  • 金額・日付の計算：入力ははい・いいえで受け、条文は「一年以内」「割合に応じて」までのため
  • ある契約が請負か委任かの判定：条文の語だけでは分けられず、本人の入力で受けるため
  • 第536条の危険負担の中身：範囲の外のため。第634条第1号・第648条3項第1号に当たらない入力では「当たりません」とだけ出し、範囲の外であることは上の「判定について」に書く
  • 第559条で売買の規定が請負に準用される中身：売買のページで引くため
  • 破産法の中身：別の法律で、民法の条は第642条に書いてある語までのため
  • 特別法（下請法、フリーランス法、労働法など）：別の法律のため
  • 時効：時効のページで引くため

条文だけで決まらなかった点（19点）：

  • （a）637条1項の「前条本文に規定する場合」が、636条本文の前半（不適合な目的物を引き渡したとき）だけを指すのか、材料・指図によって生じた場合に限るのかは語だけで言い切れない → 前半を指すと読み、材料・指図によらない不適合でも通知の問いを出す。これは読みです
  • （b）648条の2第2項は634条を準用するが、「仕事」「請負人」「注文者」を何に読み替えるかを書いていない → 成果を得るための事務・受任者・委任者と読む。これは読みです
  • （c）成果に対して報酬を払う約束に648条3項も及ぶかは648条の2が言い切っていない → 成果に対して報酬を払う約束では634条の準用の答えだけを出し、648条3項は出さない。これは読みです
  • （d）656条は「この節の規定」を準用するとだけ書き、法律行為でない事務の委託で644条の2第2項の問いが成り立つかは書いていない → 他の問いは同じに出し、代理権の問いは出さない。これは読みです
  • （e）652条が準用する620条は「賃貸借の解除」の文 → 「委任の解除は将来に向かってのみ効力を生じる。損害賠償の請求を妨げない」と読み替えて出し、原文も並べる。これは読みです
  • （f）653条は「次に掲げる事由によって終了する」と書くが、当事者の約束で別に定められるかは書いていない → 列挙のとおりに出す。約束で変えられるかは、この条には書いてありません（判定ページには出さず、ここにだけ書く）
  • （g）633条ただし書は624条1項を準用するが、「労働者」「労働」を何に読み替えるかを書いていない → 「約した仕事を終わった後」と読む。これは読みです
  • （h）641条の「仕事を完成しない間」に、完成できなくなった後や既に解除された後が入るかの語は無い → 完成した後は当たらないと出し、完成できなくなった後も当たると出す。既に解除された後（途中で終わった・注文者の破産で請負人か破産管財人が解除した）は、641条の答えを出さない。これは読みです
  • （i）642条2項・3項の「前項に規定する場合」「第一項の場合」が、解除ができない入力（請負人・完成後）を含むかの語は無い → 解除できるときだけ出す。これは読みです
  • （j）648条2項本文の「履行した後でなければ」と648条3項の関係を書いていない → 履行できなくなった・中途で終了したときは2項本文の定めと3項の答えを別の段で並べる。これは読みです
  • （k）期間によって報酬を定めたときに648条3項が及ぶかの語は無い → 3項は定め方を分けていないので、履行後と同じに出す。これは読みです
  • （l）成果が引渡しを要しないときの支払の時期が648条2項本文に戻るかの語は無い → 648条の2第1項に当たらないと出すまでにする
  • （m）648条の2第2項が準用する634条第2号の「仕事の完成前に解除」を成果の約束でどう読むかの語は無い → 「成果を得る前に解除」と読み、「履行の中途で終了」の欄は成果の約束では置かない。これは読みです
  • （n）654条の「委任が終了した場合」・655条の「委任の終了事由」に、解除で終了した場合が入るかの語は無い → 653条の列挙を入力したときだけ聞く。これは読みです
  • （o）644条の2第2項の「選任したとき」に、第1項で選任できない入力が入るかの語は無い → 第1項と別の段で並べる。これは読みです
  • （p）636条の「引き渡したとき」「仕事が終了した時」と、634条・641条の「完成」の関係を書いていない → 不適合の欄は完成の欄と別に聞く。これは読みです
  • （q）650条2項で債務が弁済期にないとき、前段の弁済の請求もできるかの語は無い → 「この場合において」なので前段と後段を並べて出す。これは読みです
  • （r）651条2項の第1号と第2号の両方に当たるときの関係は書いていない → 別の段で並べ、ただし書はどちらにも当てる
  • （s）成果に対して報酬を支払う約束が648条1項の「特約」に入るかの語は無い → 特約があるという入力の中の定め方の1つとして聞く。これは読みです
