収録範囲・仕組み

「解雇と労働契約の決まりを逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

労働契約法の本則のうち、第2条・第6条〜第21条をルールにしています。第1条・第3条〜第5条は下の地図で原文を読めますが、判定には使っていません。

起きたことと、あなたの考えを聞く27個の欄から、同じ入力で第7条〜第21条を全部当てます。話を先に選ばせることはせず、欄を出したり消したりもしません。小見出し（この法律が当たるか・解雇・懲戒・出向・就業規則と労働条件・労働条件の変更・期間のある契約）は欄の並びの目印です。その話で使わない欄は、判定で見ないだけです（下の「話ごとに見る欄」）。懲戒解雇のように1人に2つの話が重なるときは、両方の答えを出します。

範囲の外：この法律の条文に当たらないことは「有効」ではありません。第14条〜第16条で無効とされる場合に当たらなくても、解雇・懲戒・出向が有効という答えにはなりません。労働基準法第19条など別の法律の禁止は別に当たることがあり、このページでは読んでいません。

判定について：

  • 合理的な理由があるか、社会通念上相当か、権利の濫用か、やむを得ない事由か、合理的な期待があるか、就業規則の労働条件や変え方が合理的か、就業規則が法令や労働協約に反するか、遅滞なくかは、このアプリでは判定しません。欄名や選択肢に「（あなたの考え）」とあるものは、本人がそう考えたとして答えます。
  • 条文だけを読んでいます。判例、通達は載せません。実際の事件でどう判断されるかは判例と個別の事情で決まり、選び方で答えは変わります。
  • 労働基準法・船員法など別の法律は読んでいません。船員について第20条第2項が読み替える船員法第97条・第98条・第100条の中身も読んでいないので、読み替えの文だけを答えます。個別のことは法律の専門家に聞いてください。
  • 第18条第1項の通算は、2013年4月1日以降に始まった有期労働契約から数えます（改正法の附則の定め。厚生労働省「有期契約労働者の無期転換サイト」の Q&A「通算契約期間は、平成25（2013）年4月1日以降に開始した有期労働契約から算定（カウント）します。」）。このアプリは附則を読まないので、21の欄の説明に書き、本人の選択で受けます。
  • 第18条第2項で、空白より前の契約期間が1年に満たないときの期間は、省令で決まっています。「法第十八条第二項の厚生労働省令で定める期間は、同項の当該一の有期労働契約の契約期間に二分の一を乗じて得た期間（一月に満たない端数を生じたときは、これを一月として計算した期間とする。）とする。」（労働契約法第十八条第一項の通算契約期間に関する基準を定める省令 第2条。平成24年厚生労働省令第148号。e-Gov法令検索）。22の欄の「半分」はこの期間で、欄の説明に端数の数え方を書いています。
  • 結論の箱には判定だけを書きます。入力した事実（「〜ので」の理由）と、条文の読みは、論理の木の行にだけ置いています。

話ごとに見る欄：1の欄が国や地方公共団体か、2の欄が「はい」なら、第21条の答えだけを出し、ほかの欄は見ません。頭の欄が「無い」側（されていない・受けていない・命じられていない・就業規則はない・変えられていない・5年未満で空白なし・申し込んでいない・断られていない）なら、その話の答えを出しません。どの話も入っていないときは「答える条はありません」とだけ答えます。

アプリの約束事（この法律の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • 「当たりません」「適用されません」の答えは、条に当たらないと言うだけで、反対の結論を言うものではない。解雇・懲戒・出向が有効という答えでもない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例・通達：条文だけを読むアプリのため
  • 労働基準法（第11条の第89条・第90条、解雇の禁止の第19条など）：読んでいないため
  • 船員法：第20条が読み替えを書く第97条・第98条・第100条を読んでいないため。読み替えの文を出すだけで、中身は判定しない
  • 厚生労働省令：第18条第2項の「連続すると認められるものとして厚生労働省令で定める基準」（省令第1条）は読んでいないため。省令第2条の期間だけを22の欄の値に使う
  • 第18条の特例を定める他の法律があるか：読んでいないため
  • 第1条・第3条〜第5条：依頼の範囲で判定に使わないため。地図で原文だけ出す
  • 改正の経過措置（附則）：本則の範囲だけを読むため。附則の第18条の適用の定めは、通算の起点だけを21の欄の説明と上の「判定について」に書いた

条文だけで決まらなかった点（26点）：

  • （a）第15条・第16条・第19条の「客観的に合理的な理由を欠き、社会通念上相当であると認められない」→ 1つの評価として本人に聞く（6・9・27の欄の「理由と重さ」の2値）。片方だけ当たる入力は作らない。これは読みです
  • （b）有期労働契約の契約期間の途中の解雇で、第17条第1項と第16条の関係 → 第16条は「解雇は」と書いて契約の種類を分けていないが、関係は条文に書いていない。契約期間の途中は第17条第1項だけを答え、第16条の答えは出さない。第17条第1項に反した解雇の効力も書いていないので、「解雇することができません」までを答える。これは読みです
  • （c）第18条第1項の「五年を超える」と、1つの有期労働契約だけで五年を超える場合 → 条文は「二以上の有期労働契約」の契約期間を通算すると書くので、1つの契約だけの期間には「当たりません」と答える。厚生労働省の無期転換サイトの説明も「有期労働契約が通算で5年を超えて更新された場合」と書く
  • （d）第18条第2項の「連続すると認められるものとして厚生労働省令で定める基準」と、直前の契約期間が一年に満たないときの期間 → 基準（省令第1条）は読まない。空白があったかは本人の選択で受ける。期間は省令第2条の「二分の一・1か月に満たない端数は1か月」を22の欄の値と説明に入れた（上の「判定について」に原文と出典）
  • （e）第9条の「不利益」でない変更を就業規則でするときの扱い → 第9条本文の禁止には当たらない、とだけ答える。第10条の文は不利益な変更に限っていないが、扱いは条文だけでは決まらないので、第10条の答えは出さない
  • （f）第20条第1項の「前章」→ 第20条は第五章にあり、XML の章立てで第四章（期間の定めのある労働契約）は第17条〜第19条なので、第17条〜第19条と読む
  • （g）第7条本文に当たらないときの契約の内容 → 第7条に書いていない。「第7条本文には当たりません」で止める
  • （h）第12条と第7条の関係 → 第12条の文は合理性や周知を条件にしていないので、第7条本文に当たらないときも、就業規則より悪い条件を決めた部分には第12条を別に答える。これは読みです
  • （i）第7条ただし書・第10条ただし書の「この限りでない」→ その部分は第7条本文によらず決めた条件によると読み、第10条ただし書の部分は変更されないと読む。これは読みです
  • （j）第8条の合意で変えた労働条件と第12条の関係 → 第12条の文は合意の時期を分けていないので、基準に達しない部分には第12条が掛かると読む。合意で変えた条件が基準に達するかは欄で聞かないので、第8条の答えだけを出す。これは読みです
  • （k）第9条ただし書の「次条の場合」→ 第10条の周知と合理性の両方を満たす場合と読み、片方でも欠ければ第9条本文で変更できないと答える。これは読みです
  • （l）第10条ただし書で第12条を見るときの「就業規則で定める基準」が変更前か変更後か → 条文に書いていない。基準より悪いかは本人の選択で受ける
  • （m）第13条の「反する」「適用を受ける労働者」と、適用しないとされた後の契約の内容 → 反するかは本人の考えで受ける。適用を受ける労働者かは別に聞かず、論理の木の行に条件として書く。第8条・第9条は第13条に挙がっていない。その後の内容は判定しない
  • （n）第11条の手続を満たさなかったときの変更の効力 → 第11条に書いていない。労働基準法第89条・第90条を読んでおらず、判定しない
  • （o）第14条・第15条の「できる場合」→ 根拠が何かを書いていない。8・10の欄で、会社に懲戒・出向の決まりがあるかを本人の選択で受ける。決まりが無いときは第14条・第15条に「当たりません」と答え、できるかどうかは判定しない
  • （p）第18条第2項で空白が6か月以上（前の契約期間が1年未満なら半分以上）のとき → 空白より前の契約は通算に入らないので、21の欄では空白より後の契約だけを足してもらう（21の欄の説明）。空白が2つ以上あるときも、後ろから順に同じ読み方をする。これは読みです
  • （q）第18条第1項の通算に空白そのものを足すか → 条文は「契約期間を通算」と書くので、足さないと読む。これは読みです
  • （r）第18条第2項で空白が6か月未満（前の契約期間が1年未満なら半分未満）のとき → 第2項の「算入しない」に当たらないので、前の契約期間も通算に入ると読む。これは読みです
  • （s）第18条の特例を定める他の法律があるか、第18条第1項の「別段の定め」の中身 → 読んでいない。判定しない
  • （t）第18条第1項の申込みの方法、「契約期間の始期の到来前のもの」→ 方法は書いていない。21の欄は、まだ始まっていない契約を足さないで答えてもらう
  • （u）第17条第2項の配慮の定めに反したときの効果 → 書いていない。事実を聞かない条として、答えには出さない
  • （v）第19条の第1号・第2号に当たるか、「遅滞なく」の長さ → 25の欄で本人の考えとして受け、26の欄で「すぐに（遅滞なく）」か「しばらくしてから」かを受ける。両方に当たるときは両方の号を根拠に出す
  • （w）第19条で承諾したものとみなされた後の契約期間の長さ → 文は「同一の労働条件」と書く。その先は判定しない
  • （x）第20条第1項で第12条と第4章が外れた船員について、どうなるか → 船員法を読んでいないので判定しない。第16条は第20条第1項に挙がっていない
  • （y）第21条の「国家公務員」「地方公務員」の範囲、「同居の親族のみ」→ 本人の選択で受ける。親族を使用していない場合は「いいえ」と読む
  • （z）第2条の「労働者」「使用者」に当たるか → 判定しない。定義の原文は地図の第2条のマスで開ける
