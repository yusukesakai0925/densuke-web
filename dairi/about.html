収録範囲・仕組み

「代理の効力・無権代理を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法の本則のうち、第99条〜第118条と第653条2号をルールにしています。

入力の欄は、起きた事実を聞く27個で、いつも全部を出します。同じ入力で第99条〜第118条を全部当てるので、例えば「代理権の範囲を超える行為をした・正当な理由はない」を選ぶと、本人が責任を負うか（第110条）、本人に効くか（第113条）、相手方が取り消せるか（第115条）、行為をした人が責任を負うか（第117条）の判定が並んで出ます。前の欄の答えで意味を持たない欄（例：契約なのに選んだ16の欄、復代理人を選んでいないのに選んだ26の欄）は、答えに使いません。事実として成り立たない組は「この組み合わせはありません」と、欄の番号と根拠条を出します（選択肢の言葉どうしでぶつかるだけの組は、条を付けず欄の番号だけを出します）。裁判所などでどうなるかを当てる道具ではなく、入力のとおりなら条文がどう定めているかを確かめるものです。個別のことは法律の専門家に聞いてください。

入っていないもの：下の載せなかったものをご覧ください。

判定について：

  • 当てはめは判定しません。「正当な理由」「やむを得ない事由」「過失」「相当の期間」「自己又は第三者の利益を図る目的」「利益が相反する行為」「保存行為」「性質を変えない範囲内」に当たるかは、事情で決まり、条文だけでは決まりません。本人がそう考えているかを入力にしているだけです。
  • 条文だけを読んでいます。判例の読み方（無権代理と相続、表見代理が成り立つときに相手方が無権代理人の責任を選べるか など）は載せません。
  • 101条で影響を受ける意思表示の中身（錯誤・詐欺・強迫など）は意思表示のページで引いてください。
  • 重なりは並べて出します。同じ入力で2つ以上の条が当たるときは、どれの判定も出します。ただし、第109条・第110条・第112条で本人が責任を負うときは、第113条〜第118条の答えを出しません。重ねて使うかを定める語が条文に無いためです。本人が追認を拒絶したとき・拒絶したものとみなされたときは、第115条の取消しと第116条の答えを出しません。
  • 語の言い換え：本人＝代理を頼んだ（代理される）人。相手方＝代理人と契約などをした人。追認＝代理権の無い人がした行為を、本人が自分に効かせると認めること。催告＝期間を決めて、答えるよう求めること。復代理人＝代理人がさらに選ぶ代理人。これらは条文の語をこのアプリが言い換えたものです。
民法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（民法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。下の規則は論理の木に アプリの約束事 の印を付けて出ます。判定しないことは上の「判定について」にあります。

  • 条の要件に当たらないときは「当たりません」とだけ出し、反対の結論（ほかの理由で本人に効く・責任を負う等）は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例の基準：この範囲の条文に無く、条文だけを読むアプリのため
  • 無権代理と相続：条文に定めが無く、判例の読み方になるため
  • 委任契約の中身（643条以降。653条2号の委任者の破産手続開始の決定だけは読む）：代理の条の外で、委任の終了に当たるかは入力で選ぶため
  • 法定代理権の発生根拠：それぞれ別の条の話で、ここでは法定代理人という入力にするため
  • 商法の代理：別の法律のため
  • 他の民法の条の中身（制限行為能力の条など）：この範囲の外のため。語は入力で選ぶ
  • 代理人の死亡（111条1項2号）：死亡した代理人が後から行為をすることは無いので、2の欄の選択肢に入れていない。2号のうち破産手続開始の決定と後見開始の審判は入れている

条文だけで決まらなかった点（26点）：

  • （a）109条・110条・112条と113条〜117条を重ねて使う場面 → 重ねて使うかを定める語が無いので、109条・110条・112条で本人が責任を負う組では113条〜118条の答えを出さない。責任を負わない組・当たらない組では、続けて113条〜118条の答えを出す
  • （b）107条・108条の「みなす」のあと → 「代理権を有しない者がした行為」なので、同じ入力で113条〜118条の答えを続けて出す
  • （c）117条2項2号ただし書 → 他人の代理人として契約をした者が「知っていた」かを見る語で、「過失によって知らなかった」と組になるので、相手方の欄（13の欄）と行為をした人の欄（24の欄）の2つに分ける
  • （d）109条2項・112条2項の「前項の規定によりその責任を負うべき場合」 → 13の欄が「知らず、過失もなかった」のときと読む。そうでないときは、109条2項・112条2項に当たらないと出す
  • （e）107条・108条を読む範囲 → 1の欄が「代理権があり、その範囲内の行為をした」のときだけ読む。107条の語は「代理権の範囲内の行為」で、108条にその語は無いが同じにした。範囲内でないのに7の欄で「利益を図る目的」を選んだ組は、この組み合わせはありませんと出す
  • （f）107条・108条の「みなす」に当たらないとき → 99条・100条へ進む。「この限りでない」の先を定める語は無いので、99条1項の語で読む
  • （g）本人のためにすることを示したか（11の欄） → 99条・100条は1の欄が範囲内のときだけ読む。範囲外の行為・代理権の無い行為は、示したものだけを扱い、示さなかった組はこの組み合わせはありませんと出す（113条の「他人の代理人としてした契約」に当たるかを読まないため）
  • （h）102条を読む範囲 → 語が「代理人としてした行為」なので、99条1項・100条ただし書で本人に直接に効力を生ずる組と、110条で本人が責任を負う組だけで読む。109条・112条の語は「その他人」
  • （i）6の欄 → 102条の「制限行為能力者」と117条2項3号の「行為能力の制限を受けていた」は同じ人の同じ事実なので、1つの欄で聞く
  • （j）110条が準用する109条1項本文の「表示した者」 → 110条には表示の語が無いので、責任を負う者を本人と読む
  • （k）112条1項で相手方が消滅の事実を知っていたとき → ただし書の語は過失だけなので「この限りでない」と書かず、「代理権の消滅の事実を知らなかった第三者」に当たらないと出す
  • （l）108条2項の債務の履行 → 108条2項ただし書の語は「本人があらかじめ許諾した行為」だけなので、利益が相反する行為では10の欄を答えに使わない
  • （m）99条2項・101条 → 入力で分ける語が足りないので、本人に直接に効力を生ずる組で定めだけ出し、結論の箱には出さない
  • （n）追認を拒絶したとき・拒絶したものとみなされたときの115条・116条 → 契約が本人に効かないことが決まり、取り消す前提・さかのぼる前提が無いので出さない
  • （o）追認をしたが113条2項で相手方に対抗できないときの115条 → 「追認をしない間」に当たるかを定める語が無いので、出さない
  • （p）同じときの117条1項 → 語は「本人の追認を得たとき」で対抗の語が無いので、語どおり責任を負わないと出す
  • （q）116条で別段の意思表示があるとき → 「別段の意思表示がないとき」に当たらないと出し、いつから効力を生ずるかは出さない（別段の意思表示の中身は読まない）
  • （r）114条の確答 → 確答の中身を定める語が無いので、中身は17の欄で選ぶ。答えたのに追認も拒絶もしていない組、答えなかったのに追認した組、答えたのに追認・拒絶を相手方に対してしていない組は、この組み合わせはありませんと出す
  • （s）13の欄 → 109条1項ただし書・112条1項・115条ただし書・117条2項1号・2号の、相手方が「知っていた」「過失によって知らなかった」は、同じ相手方の同じ事実なので1つの欄で読む。117条の語に「契約の時」は無い
  • （t）117条1項で代理権を証明したとき → 1の欄が範囲内でない（行為の時にその行為の代理権が無い）のに証明した組は、この組み合わせはありませんと出す。23の欄は、107条・108条で代理権を有しない者がした行為とみなされる組で答えに使う
  • （u）117条2項の号の順 → 1号、2号、3号の順に読み、当たれば先を見ない。2号ただし書に当たれば3号を見る。順を定める語は無い
  • （v）118条の準用 → 語の「契約」を単独行為に置いて読む。後段の「同様とする」も準用と読む
  • （w）103条で権限の定めがあるとき → 定めの中身は読まないので、103条の答えは出さない。権限の定めが無いのに、5の欄の行為の種類と1の欄の範囲内・範囲外が食い違う組は、この組み合わせはありませんと出す
  • （x）委任による代理人が復代理人を選任したときの責任 → 105条の語は法定代理人だけなので、責任の範囲を出さない
  • （y）104条〜106条 → 25の欄で復代理人を選んだときだけ読む。106条は、復代理人を選任することができる組だけで、定めとして出す
  • （z）前の欄の答えで意味を持たない欄 → 答えに使わない（例：契約なのに選んだ16の欄、追認していないのに選んだ18・19の欄、復代理人を選んでいないのに選んだ26・27の欄）。事実として成り立たない組（1と2、1と2と3、2と3、3と6、1と4と5、1と7、1と11、1と23、17と20、18と20の欄）は、この組み合わせはありませんと出す。本人の破産手続開始の決定は111条1項の事由に当たらない。委任による代理権は、委任者の破産手続開始の決定で委任が終了するので（653条2号）、111条2項で消滅すると出す。法定代理権は消滅しないので、111条1項の事由に当たらないと出す。法定代理で1の欄に代理権の消滅後を選んだ組は、この組み合わせはありませんと出す
