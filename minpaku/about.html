収録範囲・仕組み

「民泊新法を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

住宅宿泊事業法の本則のうち、第2条・第3条・第5条〜第17条・第73条・第75条〜第79条をルールにしています。第18条は原文を地図に載せ、判定では使いません（下の (18)）。

収録しているのは「家と泊め方（住宅か・住宅宿泊事業か）」「届出」「管理と予約（管理業務の委託・予約の代理と仲介）」「毎日の義務」「届け出たことの変化」「区や知事からの命令・調べ」です。

条文の「都道府県知事」は、第3条第1項の括弧書きで、保健所設置市等（保健所を設置する市か特別区）の長が第68条第1項により事務を処理する区域では、その長に読み替わります。判定ページでは「区や市（都道府県知事）」と書きます。国土交通省の窓口一覧で、文京区は条例ありとされています（2026年11月26日確認）。

この XML は2026年11月9日に取得した版で、それ以後の改正と、公布済みで施行前の改正は読んでいません。

設備・家・日数の数え方・居室の数・不在の値は、住宅宿泊事業法施行規則（平成29年厚生労働省・国土交通省令第2号。e-Gov 法令API の、2025年4月1日施行の版を2026年11月26日に取得）の条文から取りました。法律が数や中身を「国土交通省令・厚生労働省令で定める」と委ねた所です。値が施行規則から来る答えには、根拠に法律の条と並べて施行規則の条も書きます（施行規則の条にはボタンを付けません）。使った条文は次のとおりです。

  • 施行規則第1条（2条1項1号の設備）：「住宅宿泊事業法（以下「法」という。）第二条第一項第一号の国土交通省令・厚生労働省令で定める設備は、次に掲げるものとする。一　台所　二　浴室　三　便所　四　洗面設備」
  • 施行規則第2条（2条1項2号の家）：「法第二条第一項第二号の人の居住の用に供されていると認められる家屋として国土交通省令・厚生労働省令で定めるものは、次の各号のいずれかに該当するものであって、事業（人を宿泊させるもの又は人を入居させるものを除く。）の用に供されていないものとする。一　現に人の生活の本拠として使用されている家屋　二　入居者の募集が行われている家屋　三　随時その所有者、賃借人又は転借人の居住の用に供されている家屋」
  • 施行規則第3条（2条3項の日数の数え方）：「法第二条第三項の国土交通省令・厚生労働省令で定めるところにより算定した日数は、毎年四月一日正午から翌年四月一日正午までの期間において人を宿泊させた日数とする。この場合において、正午から翌日の正午までの期間を一日とする。」
  • 施行規則第9条第2項（11条1項1号の居室の数）：「法第十一条第一項第一号の国土交通省令・厚生労働省令で定める居室の数は、五とする。」
  • 施行規則第9条第3項（11条1項2号の一時的な不在）：「法第十一条第一項第二号の国土交通省令・厚生労働省令で定めるものは、日常生活を営む上で通常行われる行為に要する時間の範囲内の不在とする。」
  • 施行規則第9条第4項（11条1項2号の後ろの括弧書き）：「法第十一条第一項第二号の国土交通省令・厚生労働省令で定めるときは、次の各号のいずれにも該当するときとする。一　住宅宿泊事業者が自己の生活の本拠として使用する住宅と届出住宅が、同一の建築物内若しくは敷地内にあるとき又は隣接しているとき（住宅宿泊事業者が当該届出住宅から発生する騒音その他の事象による生活環境の悪化を認識することができないことが明らかであるときを除く。）。二　届出住宅の居室であって、それに係る住宅宿泊管理業務を住宅宿泊事業者が自ら行うものの数の合計が五以下であるとき。」

入っていないもの：旅館業法（届出をしないで泊めたとき・181日以上泊めたときの扱い）、旅行業法、施行要領（ガイドライン）・判例・政令・解説書、各地の条例の中身、欠格事由（第4条）、住宅宿泊管理業者・住宅宿泊仲介業者の登録と義務（第19条以降）、マンションの管理規約や賃貸借契約で民泊ができるか。詳しくは載せなかったものをご覧ください。

判定ページは19個の欄をいつも全部出し、選んだ値によって欄を出したり消したりしません。入力に関わらない欄は、判定で見ないだけです。6つの小見出しの答えは、同じ入力で全部出します。

  • 3〜19の欄：1の欄が「どれかが無い」か、2の欄が「人が住まず、入居者の募集もしていない」なら見ません。2条1項の答えだけを出します（下の (1)）
  • 5〜19の欄：3の欄が「受けない」か、4の欄が「181日以上」なら見ません（下の (2)）
  • 6〜19の欄：5の欄が「まだ出していない」か「出さずに泊めている」なら見ません。第11条〜第17条は、どれも届出をした住宅宿泊事業者の条です（下の (4)）
  • 6・7の欄：8の欄が「事業者が自分で（事業者が住宅宿泊管理業者）」か「住宅宿泊管理業者に委託している」なら見ません（下の (6)）
  • 10の欄：8の欄が「住宅宿泊管理業者に委託している」で、10の欄が衛生〜苦情の対応なら、11条2項の答えだけを出します（下の (9)）
  • 11の欄：罰金の対象になる違反が無ければ見ません（下の (17)）
  • 14の欄：13の欄が「ない」なら見ません
  • 16の欄：15の欄が「ない」なら見ません
  • 18・19の欄：17の欄が「ない」なら見ません。19の欄は、17の欄が「業務の報告」でも見ません

「この組み合わせはありません」と出すのは1つの組です。イ：13の欄が「事業者（個人）が亡くなった」で、11の欄が「法人（会社など）の代表者・従業者」（3条6項。第1号は「住宅宿泊事業者である個人が死亡したとき」で、法人の事業者は合併・破産・解散・廃止の号です）。委託が要らないのに委託している、違反を選んでいないのに業務停止命令が来た、のような組は、起きうる事実なので段の答えで出します（下の (6)・(14)）。

業務改善命令・業務停止命令・廃止命令を裁判や不服申立てで争えるかは、このページでは判定しません。行政不服審査法は処分への不服のページ、行政事件訴訟法は処分を争う訴えのページ、命令の前の手続（行政手続法の不利益処分）は不利益処分のページで引いてください。

この法律のどこまでをルールにしたか（全条文の地図）

本則の全条文を章ごとに1マスずつ並べました。 はプログラムのルールの中で使っている条（第18条は原文の表にだけ置いた条）、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（この法律の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • ①第2条第1項・第2条第3項・第11条第1項が「国土交通省令・厚生労働省令で定める」とした設備・家・日数の数え方・居室の数・一時的な不在・住まいが近い場合は、判定ページの2・4・6・7の欄で、施行規則の値で聞く（上の施行規則の条文）。施行規則第9条第4項第1号の括弧書き（騒音などによる悪化を認識できないことが明らかなとき）は欄にせず、答えの文に条件として書く。第9条第4項第2号の「合計」は、事業者が自分で管理する全部の届出住宅の居室の数で、6の欄で受ける。第15条・第17条第1項の「必要があると認めるとき」と第16条第2項の「他の方法により監督の目的を達成することができないとき」は、命令や検査をするかを決める知事の判断で、命令や検査が来るまで利用者に分からないので、欄にせず、答えの文に「…と認めるときは」「…できないときは」と条件で書く。第10条の「適切かつ迅速」は、10の欄で苦情への対応をしているかの事実として聞き、当てはめは判定しない。第16条の「法令…に違反したとき」は、ほかの欄で選んだ違反から導く（この法律の外の法令の違反は欄で聞かない）
  • ②「当たりません」は、その条に当たらないと言うだけで、反対の結論を言うものではない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 施行要領（ガイドライン）・判例・政令・解説書：条文と、法律が委ねた施行規則だけを読むアプリのため。下の読みで出典を示した国土交通省のページは、読みを確かめるのに使っただけです
  • 具体的な衛生と安全の措置・名簿に書く事項・定期報告の事項・標識の様式（施行規則のほかの条と、厚生労働省令・国土交通省令）：欄で「しているか」だけを聞くため。定期報告の時期は、施行規則第12条第2項で「毎年二月、四月、六月、八月、十月及び十二月の十五日まで」です
  • 旅館業法での扱い（届出をしないで泊めたとき・181日以上泊めたとき）：読んでいないため。判定ページは「旅館業法第3条第1項の規定にかかわらず営むことができる、という扱いを受けません」とだけ答えます（下の (3)）
  • 各地の条例の中身（第18条）：読んでいないため（下の (18)）
  • 罰金・過料の実際の額：条文は上限だけのため
  • 提示の無いまま行われた立入検査の効果：読む範囲に効果の定めが無いため
  • マンションの管理規約や賃貸借契約で民泊ができるか：この法律の外のため。賃貸借は賃貸借のページで引けますが、民泊が又貸し（転貸）に当たるかは条文だけでは決まりません
  • 欠格事由（第4条）、第3条第6項第2号〜第5号（合併・破産・解散）、住宅宿泊管理業者・住宅宿泊仲介業者の登録と義務（第19条以降）：依頼の範囲の外のため
  • 裁判・不服申立て・損害賠償：別の法律のため。不服申立ては処分への不服のページ、裁判は処分を争う訴えのページ、命令の前の手続は不利益処分のページで引けます
  • 附則：本則の範囲だけを読むため

条文だけで決まらなかった点（19点）：

  • （1）第2条第1項の「住宅」→ 1の欄で施行規則第1条の4つの設備が全部あるか、2の欄で施行規則第2条の3つの家のどれかを聞く。どちらかが欠ければ、2条1項の答えだけを出す。施行規則第2条の「事業（人を宿泊させるもの又は人を入居させるものを除く。）の用に供されていないもの」は欄で聞かない
  • （2）第2条第3項の180日 → 「超えないもの」が定義なので、181日以上は住宅宿泊事業に当たらないと答える。日数は施行規則第3条の数え方（4月1日の正午から、正午から翌日の正午までを1日）で聞く。宿泊料を受けないときも当たらないと答える
  • （3）届出をしないで泊めるとき・181日以上泊めるとき → 「旅館業法第3条第1項の規定にかかわらず営むことができる、という扱いを受けません（3条1項）」とだけ答える。この法律の罰則の条（第72条〜第79条）に罰する文は無いが、罰が無いと読めるので答えに書かない（旅館業法は読んでいない）
  • （4）届出をしていない人 → 第2条第4項の住宅宿泊事業者に当たらないので、第11条〜第17条の欄を見ない。届出にうそを書いた人は届出をした人として、6〜19の欄も見る
  • （5）第2条第3項の「旅館業法…に規定する営業者以外の者」→ 欄で聞かず、営業者ではない前提で答える
  • （6）第11条第1項の委託 → 第1号か第2号のどちらかで要ると読む。ただし書きは、事業者自身が住宅宿泊管理業者で自ら管理業務を行うときだけ。委託が要らないのに委託しているときは、ありませんにせず第11条第2項を答える
  • （7）第11条第1項第2号の後ろの括弧書き → 施行規則第9条第4項を字面どおりに当てる。自分の住まいが届出住宅と同じ建物・同じ敷地か隣にあり、自分で管理する居室が5以下なら、委託は要らないと答え、第1号の括弧書き（悪化を認識できないことが明らかなとき）を答えの文に条件として書く。国土交通省のよくある質問は「業務等により、継続的に長時間不在となる場合は住宅宿泊管理業者への委託が必要です。」と書く（2026年11月26日確認）。条文の字面は事業者がどこにいるかを書いていないので、このアプリは欄を増やさず字面どおりに答える
  • （8）第11条第1項第2号の一時的な不在 → 施行規則第9条第3項の「日常生活を営む上で通常行われる行為に要する時間の範囲内の不在」を、7の欄の「買い物など、普段の暮らしの用事で短くあけるだけ」で聞く。国土交通省の管理業務の委託のページは「一時的な不在として認められる時間は、届出住宅が所在する地域の事情等を勘案する必要があるため、一概に定めることは適当ではありませんが、原則１時間となります。ただし、生活必需品を購入するための最寄り店舗の位置や交通手段の状況等により当該行為が長時間にわたることが想定される場合には、２時間程度までの範囲となります。」と書き、委託が要る場合を「届出住宅の居室の数が、５を超える場合」と書く（2026年11月26日確認）
  • （9）第11条第2項の「第五条から前条まで」→ 前条は第10条で、第13条（標識）と第14条（定期報告）は外れないと読む。国土交通省の住宅宿泊事業法の概要も「上記措置（標識の掲示は除く）を住宅宿泊管理業者に委託することを義務付け」と書く
  • （10）第5条・第6条・第7条・第9条・第10条をしていないとき → その条の「しなければなりません」と、第15条の業務改善命令・第16条第1項の業務停止命令の「できます」を答える。違反そのものを罰する文は罰則の条に無いが、罰が無いと読めるので答えに書かない
  • （11）第8条第2項と第77条 → 告げなかっただけでは第77条の「偽って告げた者」に当たらないと読む
  • （12）第3条第6項第1号 → 相続人が、亡くなったことを知った日から30日以内と読む。第79条の過料は第3条第6項の届出全体（廃止も死亡も）にかかると読む
  • （13）第3条第4項 → 住所の変更は第2項第1号で30日以内、委託する管理業者の変更は第2項第6号であらかじめと読む
  • （14）第16条第1項・第2項の「法令…に違反したとき」→ ほかの欄で選んだ違反（届出のうそ・委託が要るのにしない・予約をそれ以外に頼む・義務をしていない・変化の届出をしない・業務改善命令に従わない・調べを断る）から導く。違反を選んでいなくても業務停止命令・廃止命令の答えは「当たらない」にせず、条件を書いた文で答える（消防法など、この法律の外の法令の違反は欄で聞かないため）。業務改善命令を先に出すことは第16条第1項の条件に書いていない
  • （15）第16条第3項の通知 → 業務停止命令か廃止命令を受けたときに出す
  • （16）第17条第2項 → 「請求があったとき」の限定が無いので、関係者が求めなくても提示しなければならないと読む。第17条に、立ち入る前に通知する定めは無い
  • （17）第78条 → 第72条〜第76条の罰金だけで、第77条の拘留・科料と第79条の過料には及ばないと読む。「法人若しくは人の代理人、使用人その他の従業者」なので、個人の事業者の従業者・代理人が違反したときも、個人の事業者に罰金刑が科されると読む
  • （18）第18条の条例 → どの入力でも同じ文になるので、判定ページの答えにしない。都道府県（第68条第1項の保健所設置市等の区域では、その市や区）は、騒音などで生活環境が悪くなるのを防ぐため必要があるときは、合理的に必要と認められる限度で、政令の基準に従い、条例で区域を定めて、住宅宿泊事業を実施する期間を制限することができる
  • （19）語の開き方 → 「拘禁刑」「拘留」「科料」「罰金」「過料」「業務改善命令」などは、判定ページでは条文の語のまま書く。罰金・拘禁刑・拘留・科料は刑罰で、過料は刑罰ではない（拘留は短い期間、刑事施設に入れる刑罰。科料は少額のお金を納めさせる刑罰）
