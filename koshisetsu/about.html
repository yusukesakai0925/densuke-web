収録範囲・仕組み

「公の施設を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

地方自治法の本則のうち、第244条、第244条の2、第244条の3、第244条の4をルールにしています。

収録しているのは「施設の利用を断ること・差別的取扱い」「利用の決定への審査請求の出し先と、議会への諮問・報告」「施設の決まりを条例で定めること・特に重要な施設をやめるときの議会の同意・区域の外の施設」「施設の管理を団体に任せること（指定管理者）」です。

「公の施設」は、第244条1項で次のように定められています。判定ページで聞いている施設が公の施設に当たるかは判定せず、当たることを前提にしています（下の約束事③）。

第二百四十四条（公の施設）第1項　普通地方公共団体は、住民の福祉を増進する目的をもつてその利用に供するための施設（これを公の施設という。）を設けるものとする。

入っていないもの：「正当な理由」「不当な差別的取扱い」に当たるか（自治体や裁判所が決める評価で、このアプリは本人がそう考えているかを入力にするだけです。下の約束事①）、各自治体の条例の中身（約束事④）、判例と総務省の通知（条文だけを読むアプリのため）。審査請求の一般の手続は行政不服審査法のページ、損害賠償は国家賠償法のページです。詳しくは載せなかったものをご覧ください。

判定ページは18個の欄をいつも全部出し、選んだ値によって欄を出したり消したり、欄の名前を変えたりしません。入力に関わらない欄は、判定で見ないだけです。

  • 5の欄（審査請求）：「していない」なら、審査請求の答えを出しません
  • 8の欄（議会の同意）：7の欄が「しない」「条例で特に重要とされていない施設をやめる・長く使わせる」のときは見ません（244条の2第2項の同意は、条例で特に重要とされた施設だけの定め）
  • 10の欄（話し合いと議会）：9の欄が「しない」のときは見ません
  • 12〜18の欄：11の欄が「任せていない」なら見ません。「団体でない個人」なら、管理を任せられないという答えだけを出し、12〜18の欄は見ません
  • 1・3・4の欄の「当たりません」（住民でない・認められた・断ったわけは筋が通っている・同じ扱い）は、ほかに答えが1つも無いときだけ出します
  • 条文の定めのとおりの値（期間を決めた・議決を経た・報告書を出している・20日以内に意見が出た・指示に従っている・報告の求めなどが無い）では、答えを出しません

「この組み合わせはありません」と出すのは2つの組です。ア：2の欄が「施設の管理を任された団体（指定管理者）」で、11の欄が「任せていない」（244条の2第3項。指定管理者は、自治体が施設の管理を任せた団体）、イ：2の欄が「指定管理者」で、11の欄が「団体でない個人」（244条の2第3項は「法人その他の団体」）。2つの組は11の欄の違う値から出るので、1つの入力で重なりません。

特別区について：ここの条の語は「普通地方公共団体」で、特別区に直接触れていません。第283条1項の原文は次のとおりです。特別区がこのページの答えをそのまま使えるかは書いていません。

第二百八十三条（市に関する規定の適用）第1項　この法律又は政令で特別の定めをするものを除くほか、第二編及び第四編中市に関する規定は、特別区にこれを適用する。

地方自治法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（地方自治法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • ①「正当な理由」「不当な差別的取扱い」は自治体や裁判所が決める評価なので、このアプリは当たるかを判定しない。判定ページで「（あなたの考え）」と付けた欄に、本人がそう考えているかを入れてもらう
  • ②「当たりません」は、その条に当たらないと言うだけで、反対の結論を言うものではない
  • ③判定ページで聞いている施設が「公の施設」（第244条1項）に当たるかは判定せず、当たることを前提にする
  • ④条例の中身は読まない。条文が「条例で定める」「条例の定めるところにより」と書いている中身は自治体ごとに違うので、条例で定めているかどうかを欄で聞く
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例と総務省の通知：条文だけを読むアプリのため
  • 各自治体の条例の中身：自治体ごとに違い、法律の本則だけを読むため
  • 行政不服審査法の手続の中身：別の法律で、行政不服審査法のページがあるため
  • 第96条など議決事件の一般の定め：公の施設の章の外のため
  • 地方独立行政法人の公の施設：別の法律の定めのため
  • 損害賠償：国家賠償法の話で、国家賠償法のページがあるため

条文だけで決まらなかった点（13点）：

  • （a）244条2項・3項は「住民」と書き、住民でない人の扱いは書いていない → 2項・3項には当たらないと答え、断ってよいとは言わない（約束事②）
  • （b）244条の4第1項は長以外の機関（指定管理者を含む）がした処分の定めで、知事・市町村長自身の処分の出し先は書いていない。第2項は処分全般を言う → 知事・市町村長がした決定は第1項に当たらないと答え、第2項〜第4項は知事・市町村長がした決定にも及ぶと読む
  • （c）244条の4第3項の20日を過ぎて意見が無いとき、どうなるかは書いていない → 議会は20日以内に意見を述べなければならないとだけ答え、過ぎた後どうなるかは答えない
  • （d）244条の2第9項の「公益上必要があると認める場合」に利用料金を誰が定めるかは書いていない → 16の欄で「公益のために自治体が決めた」と聞き、指定管理者が利用料金を決める定めから外れるとだけ答える
  • （e）244条の2第5項の期間を定めなかった指定、第6項の議決を経なかった指定の効力は書いていない → 期間を決めて行う・議決を経なければならないとだけ答え、指定が無効かは答えない
  • （f）244条の2第2項の同意が要るのは「条例で定める」特に重要なものに限る → 7の欄で、条例で「特に重要」とされた施設かを聞き、そうでなければ同意の答えを出さない。どの施設が「特に重要なもの」に当たるかは、自治体の条例に施設の種類で書いてある
  • （g）特別区 → ここの条の語は「普通地方公共団体」で特別区に直接触れていないので、そのまま使えるかは書かず、上の範囲の節の1行と第283条1項の原文に留める
  • （h）244条の2第9項後段の「この場合」は、公益上必要があると認める場合にも承認が要るかが語だけでは言い切れない → 前段の指定管理者が定める場合を指すと読み、公益のために自治体が決めたときは承認を聞かない
  • （i）請求の形が整っていないとして退けるのに議会に聞いたとき、244条の4第3項の20日がかかるかは書いていない。第4項は「諮問をしないで」退けたときの定め → 審査請求の出し先の答えだけを出し、第3項・第4項の答えは出さない
  • （j）244条の2第2項の同意、第9項の承認、244条の3第3項の議決、244条の4第2項の諮問を欠いたときの効力は書いていない → 足りない・しなければならないとだけ答え、効力は答えない
  • （k）244条の2第7項の事業報告書を出さないことと第11項の取消し・停止の関係は書いていない → つなげず別々の答えとして出す
  • （l）244条2項の「拒んではならない」と、244条の4の「公の施設を利用する権利に関する処分」は別々の条の語 → 2の欄で利用を決めた（断った）者を1つだけ聞き、審査請求の対象は2の欄の者がした利用の決定と読む
  • （m）244条の2第8項は「適当と認めるときは」指定管理者の収入にさせることができると書く → 欄にせず、16の欄で指定管理者の収入にさせたなら、自治体が適当と認めていると読む
