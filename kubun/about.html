収録範囲・仕組み

「マンションの決議を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

建物の区分所有等に関する法律の本則のうち、第6条、第17条、第18条、第31条、第34条〜第37条、第38条の2、第39条、第45条、第57条〜第60条、第62条をルールにしています。

1回の集会で起きた事実を42の欄で聞き、誰が開けるか、招集の通知は足りているか、決議は通るか、工事や規約の変更をできるか、困った住人に何を求められるかを、同じページで答えます。裁判所などでどうなるかを当てる道具ではなく、欄で選んだ事実に条文を当てるとどうなるかを確かめるものです。個別のことは法律の専門家に聞いてください。

入っていないもの：下の載せなかったものをご覧ください。共有の一般の決まりは共有のページで引いてください。

この法律のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。

アプリの約束事（この法律の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • 「当たりません」は、その条に当たらないと言うだけで、反対の結論を言うものではない
  • 45条1項は、区分所有者全員の承諾があれば書面か電磁的方法で決議できると言うだけなので、賛成の数を聞いていないこのアプリでは、承諾だけで集会の決議があったとは扱わない
  • 36条・34条は招集できないと言うだけで、そのまま開いた集会の決議がどうなるかは書いていないので、このアプリでは決議が通らなかったと扱う
  • 35条1項・37条1項・58条3項・62条6項・62条8項は手続を定めるだけで、手続の要件が欠けたままの決議がどうなるかは書いていないので、このアプリでは決議の数を判定せず、決議が通らなかったと扱う
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例：条文だけを読むアプリのため
  • 第1条〜第5条の2（定義）：決議の判定の前提で、言葉の当てはめは本人の選択にするため
  • 第6条第2項・第4項：共同の利益に反する行為の請求の判定に使わないため
  • 第6条の2（国内管理人）：集会の判定の外のため
  • 第7条〜第16条（共用部分の持分ほか）：議決権は数で入力するため
  • 第19条〜第30条（管理者ほか）：依頼の範囲の外のため
  • 第32条・第33条：規約の保管などで、変えられるかの判定の外のため
  • 第40条〜第44条：議決権の行使の細目と議事録で、数の判定の外のため
  • 第46条以降の管理命令：依頼の範囲の外のため
  • 第47条〜第56条の7（管理組合法人）：依頼の範囲の外のため
  • 第61条（復旧）：依頼の範囲の外のため
  • 第63条・第64条以降（売渡し請求、更新・売却の決議）：建替え決議の後の手続と別の決議のため
  • 第65条以降（団地・滅失）：一棟の建物の話に絞るため
  • 第86条以降（裁判の手続）：別の手続のため
  • 改正の経過措置：本則だけを読むため

条文だけで決まらなかった点（15点）：

  • （a）第35条第1項の「一週間前」の日の数え方（会日を入れるか）は書いていない → 13の欄は日数でなく「会日の1週間前から2か月前まで」などの3択で聞き、1週間前までに発したなら足りると答える。日の数え方は読んでいない。これは読みです
  • （b）第17条第1項の規約の割合が「二分の一を超える割合に限る」に当たらないとき、その規約がどうなるかは書いていない → 括弧書きに当たらないので四分の三で答える。これは読みです
  • （c）第62条第1項に出席の定足数が書かれていない → 欠席も分母に入ると答える。これは読みです
  • （d）第38条の2の裁判で議決権を有しない者を括弧書きで除くとき、議決権の総数からも引くかは書いていない → 引いて答える。これは読みです
  • （e）第34条第4項は「発せられなかつたとき」とだけある → 通知の会日が四週間より後の場合も招集できると答える。これは読みです
  • （f）第57条第2項の決議の割合は同条に書いていない → 第39条第1項の普通の決議で答える。これは読みです
  • （g）第17条第5項の読み替えの後、規約の割合が三分の二以上で四分の三を下回るとき → 三分の二を基準に見て、括弧書きに当たらないと答える。これは読みです
  • （h）定足数の規約の割合が過半数を上回らないとき、その規約がどうなるかは書いていない → 過半数で答える。第31条第1項・第58条第2項も同じに扱う。これは読みです
  • （i）第34条第4項の「二週間以内」の起点は「請求がされた場合において」とあるだけ → 請求の日からと読む。これは読みです
  • （j）第34条第3項・第5項の「規約で減ずる」に、五分の一以上の割合は当たらない → 五分の一で答える。これは読みです
  • （k）第34条に、管理者がいるときに区分所有者がそのまま招集する場合は書いていない → できないと答える。管理者に請求した後に区分所有者が招集できるか（第34条第4項）は、6の欄で「区分所有者が、管理者に招集を請求した」を選んだときに同じページで答える。これは読みです
  • （l）第39条第1項・第18条第2項の規約の別段の定めの中身は読めない → 普通の決議と共用部分の管理の決議は、別段の定めが無いものとして過半数で答える（27・28の欄の規約の割合は使わない）。第18条第2項は、20の欄が「書いてある」なら規約の定めによると答え、規約の中身は読まない。これは読みです
  • （m）第57条第4項の準用で、占有者への請求者の「他の区分所有者の全員」をどう読むかは書いていない → 第60条第1項に合わせて「区分所有者の全員」と答える。これは読みです
  • （n）第59条第3項の月の数え方は書いていない → 41の欄の月数が6以下ならまだできると答える。月の数え方は読んでいない。これは読みです
  • （o）第18条第6項は損害保険の契約を共用部分の管理に関する事項とみなすが、専有部分の工事を一緒に決めるとき第18条第4項が当たるかは書いていない → 管理とみなすので、30の欄は第18条第4項で答える。これは読みです
