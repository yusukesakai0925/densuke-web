収録範囲・仕組み

「組合の脱退と解散を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法（明治二十九年法律第八十九号）の本則のうち、第三編 債権 第二章 契約 第十二節 組合の第678条〜第688条（第680条の2を含む12か条）を、全部ルールにしています。この中で当てはめられる（準用される）第620条・第670条第3項〜第5項・第670条の2第2項・第3項・第672条も、原文を並べています。

起きたことと、あなたの考えを聞く26個の欄から、同じ入力で第678条〜第688条を全部当てます。話を先に選ばせることはせず、欄を出したり消したりもしません。小見出し（組合員が抜ける・追い出される・抜けた人のお金・組合がなくなる（解散）・清算）は欄の並びの目印です。その話で使わない欄は、判定で見ないだけです（下の「話ごとに見る欄」）。1人が抜けて組合も解散したときのように、2つの話が重なるときは両方の答えを出します。

ここでいう組合は、民法の組合（何人かがお金や手間を出し合って一緒に事業をする約束）です。会社（株式会社）や労働組合とは別物です。

この XML は2026年11月4日に取得した版（定型約款の Prolog と同じファイル）で、それ以後の改正と、公布済みで施行前の改正は読んでいません。

判定ページでは原文をそのまま並べ、その横にこのアプリの言い換えを置いています。原文は直していません。

組合の節のうち第667条〜第677条の2（当てはめられる第670条第3項〜第5項・第670条の2第2項・第3項・第672条を除く）、判例、破産法・後見の各条、税法、有限責任事業組合法・投資事業有限責任組合法は読んでいません。組合から抜けさせない約束が効くかについても、判例を読んでいないので判定しません。組合の成り立ちや仕事の決め方は組合のページで、賃貸借の定めは賃貸借のページで扱っています。

附則は読んでいません。

判定について：

  • やむを得ない事由・組合に不利な時期・正当な事由・事業の成功に当たるか、常務（日々の決まりきった小さな仕事）かは、このアプリでは判定しません。欄名や選択肢に「（あなたの考え）」とあるものと、清算人の役の欄の「正当な事由」は、本人がそう考えたとして答えます。
  • 「従前の責任の範囲」（抜ける前に負っていた責任の範囲）の額、取り分（持分）の額、残った財産の額と、組合員それぞれがいくらずつになるかは、聞かず、計算しません。抜けた人が組合員だった間に負っていた責任の中身は、第667条〜第677条の2を扱う組合のページの範囲です。
  • 条文だけを読んでいます。判例・解説書は載せません。第678条のほかに組合から抜ける道があるか、亡くなった組合員の相続人が組合員になるか、組合契約を解除できるか、清算人の辞任のほかの手続は、この範囲の条文に書いていないので答えません。
  • 破産法・後見の各条・税法・有限責任事業組合法・投資事業有限責任組合法など、別の法律は読んでいません。個別のことは法律の専門家に聞いてください。
  • 結論の箱には判定だけを書きます。入力した事実（「〜ので」の理由）と、条文の読みは、論理の木の行にだけ置いています。

話ごとに見る欄：頭の欄が「無い」側（何もない・求められていない・求めていない・払っていない・まだ返していない・ない・何も起きていない・いいえ・特にない）なら、その話の答えを出しません。どの話も入っていないときは「答える条はありません」とだけ答えます。抜けられない・除名できないときは、抜けた人のお金の答えを出しません。解散していないとき（14の欄が「何も起きていない」）は、清算の欄を見ません。15の欄で解散を求めた、16の欄で組合の約束をやめた、だけでは解散した組にしません（第683条は「請求することができる」まで、第684条は解除の効力の定めです）。

この法律のどこまでをルールにしたか（全条文の地図）

民法の本則の全条文を、編・章ごとに1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条、斜線は削除された条です。マスを押すと原文が出ます。第670条・第670条の2は、当てはめられる項だけを出します。

語の意味

組合＝何人かがお金や手間を出し合って一緒に事業をする約束（会社や労働組合とは別のもの）。組合員＝組合に加わっている人。脱退＝組合から抜けること。除名＝組合員を組合から追い出すこと。存続期間＝組合が続く期間。終身＝ある人が生きている間。やむを得ない事由＝どうしようもない事情。不利な時期＝組合にとって都合の悪い時期。正当な事由＝もっともな理由。一致＝そろって賛成すること。通知＝知らせること。対抗することができない＝相手に「そうなった」と言い張れない。債務＝払う義務、借金。弁済＝借金などを払うこと。債権者＝お金などを求める権利がある人。従前の責任の範囲内＝抜ける前に負っていた責任の範囲で。担保を供させる＝借金の支払いを確かにするための物や保証を出させること。免責を得させる＝自分の責任を免れさせること。求償権＝立て替えて払った分を返してと言える権利。持分＝組合財産の中の自分の取り分。払い戻す＝取り分を返すこと。出資＝組合のためにお金・物・手間を出すこと。解散＝組合がなくなること。清算＝事業をたたんで貸し借りを片付け、残った財産を分けること。清算人＝清算を受け持つ人。総組合員＝組合員全員。過半数＝人数の半分を超える数（ちょうど半分は入らない）。常務＝日々の決まりきった小さな仕事。異議＝反対の申し出。代理＝ほかの人の代わりに、その名で相手と約束すること。辞任＝自分から役を降りること。解任＝役から外すこと。解除＝約束を一方からの申し出でやめること。準用＝別の定めを、合うように読み替えて当てはめること。現務の結了＝今している仕事を終わらせること。残余財産＝貸し借りを片付けて残った財産。出資の価額＝出した物の値打ちをお金に直した額。これらは条文の語をこのアプリが言い換えたものです。

アプリの約束事（この法律の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • 「当たりません」の答えは、条に当たらないと言うだけで、反対の結論を言うものではない
  • 「従前の責任の範囲」の額・持分の額・残った財産の額は聞かず、計算しない（論理の木には付けない。上の「判定について」）
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • やむを得ない事由・不利な時期・正当な事由・事業の成功に当たるか、常務か：事情で決まり、条文だけでは決まらないため判定しません。欄名・選択肢の「（あなたの考え）」で、本人がそう考えたとして答えます
  • 「従前の責任の範囲」の額・持分の額・残った財産の額の計算：この範囲の条文に計算のしかたが無いため判定しません
  • 組合の約束によらず選んだ清算人と、組合員でない清算人の辞任・解任ができるか：第687条の文言は、組合の約束で決めたやり方で組合員の中から選んだときだけです。この2つは「第672条は当てはまらない」とだけ答え、辞任・解任できるかは判定しません
  • 亡くなった組合員の相続人の扱い：この範囲の条文に無いため判定しません
  • 組合から抜けさせない約束が効くか：判例を読んでいないため判定しません
  • 第667条〜第677条の2のうち当てはめられない条：今回の範囲の外のため読んでいません（組合のページで扱っています）
  • 判例・解説書・破産法・後見の各条・税法・有限責任事業組合法・投資事業有限責任組合法：条文だけを読むアプリで、ほかの法律は読まないため
  • 附則：本則の範囲だけを読むため

条文だけで決まらなかった点（25点）：

  • （1）第678条第2項 → 存続期間を決めていて、やむを得ない事情がないときは「抜けられるのは、やむを得ない事由があるときだけ」と答える。第678条のほかに抜ける道があるかは、この範囲の条文に書いていない
  • （2）1ページ → 26の欄を同じ入力で全部当て、頭の欄が「無い」側の話の答えは出さない。抜けられない・除名できない組では抜けた人のお金の答えを、解散していない組では清算の答えを出さない（前提が消えた組）
  • （3）第678条第1項 → 存続期間を決めていない・終身で、不利な時期でないときは、4の欄（やむを得ない事情）を見ない
  • （4）第680条 → 正当な事由がないときは6・7の欄を見ずに「除名できない」と答え、一致がないときは7の欄を見ない。除名して知らせていないときは「除名できる」と「対抗できない」の2つを答える
  • （5）第680条の2第1項 → 抜けた後に生じた債務は「第680条の2第1項が払わせるのは、抜ける前に生じた債務」とだけ書き、払うかどうかは書かない
  • （6）第680条の2第1項後段 → 債権者が全部の弁済を受けたときは、後段の求めに当たらないと書く
  • （7）第680条の2第2項 → まだ払っていないときは、第680条の2第2項の答えを出さない
  • （8）第682条 → 第1号〜第4号のどれも起きていないときは答えを出さない。「ある組合員が生きている間続く」と決めた組合で14の欄が「存続期間が終わった」のときは、「この組み合わせはありません」にせず、第682条第2号で「解散します」と答える（終身が存続期間の定めに当たるかは条文だけでは決まらない）
  • （9）第683条 → やむを得ない事情がないときは「請求できるのは、やむを得ない事由があるとき」と答える。解散を求めただけでは、解散した組にしない
  • （10）第685条第1項 → 「総組合員が共同して、又はその選任した清算人が」を、清算人を選んだかどうかで分けて答える
  • （11）第685条第2項・第686条 → 過半数は人数の半分を超える数とし、ちょうど半分は過半数に入れない
  • （12）第686条 → 第670条第3項〜第5項・第670条の2第2項・第3項の「業務執行者」を清算人と、「組合の業務」を清算の仕事と読み替える
  • （13）第686条・第670条第4項 → 組合員全員の同意は、清算人が1人でも数人でも見る
  • （14）第686条・第670条の2第2項 → 代理は清算人が代理する場合だけを聞き、清算人でない組合員が代理できるかは聞かない
  • （15）第686条・第670条の2第3項 → 代理の常務には第670条第5項のような異議のただし書が無いので、異議の欄を見ない
  • （16）第686条・第670条第5項 → 異議はだれが述べたかを分けず「ほかの清算人など」と聞く
  • （17）第687条 → 組合の約束によらず多数決で選んだ清算人と、組合員でない清算人の辞任・解任は「第672条は、組合の約束で組合員の中から選んだ清算人の定め」と答える（当たらない）
  • （18）第687条・第672条第1項 → 正当な事由があるときは「辞任できない」に当たらないとだけ書き、「辞任できる」とは言い切らない
  • （19）第684条・第620条 → 解除できるかは条文に書いていないので答えず、解除が将来に向かってだけ効くことだけを書く。第620条の損害賠償の文は原文に並べるが答えには書かない
  • （20）第679条第1号 → 亡くなった組合員の相続人の扱いは判定しない
  • （21）第681条第2項 → お金を出資した人にも、物・労務と同じく「お金で返してよい」と答える（出資の種類を問わないため）
  • （22）第688条 → 欄を置かず、第1項・第2項は清算人を選べた組で、第3項は解散した組で、いつも答える
  • （23）答えの状態 → 「この組み合わせはありません」「できない」「当たる」「当たらない」の4つにした（前の「判定しない」はやめた）
  • （24）語の開き方 → 上の「語の意味」と、条文ごとの言い換え（35行）は、このアプリの言葉
  • （25）原文の表 → 号のある項（第679条・第682条・第688条第1項）は号ごとの行にし、項の頭の文は行にせず、号のボタンで一緒に出す
