収録範囲・仕組み

「婚姻と離婚を逆から引く」で、どの条文をどこまでルールにしたか、アプリが決めたこと、プログラムの中身です。

収録範囲と、入っていないもの

民法の本則のうち、第731条〜第752条、第755条〜第765条、第766条第1項・第2項、第767条〜第771条をルールにしています。第733条・第737条・第746条・第753条・第754条・第757条は削除です。

判定ページの欄は、起きた事実を聞く31個で、いつも全部出ています。同じ入力で、第731条〜第771条を全部当てます。婚姻の届出が受理される前なら第740条（受理できない）、受理された後なら第744条・第745条・第747条（取消し）に当てます。どの条の話かを先に選ぶ欄は置いていません。個別のことは法律の専門家に聞いてください。

事実が関係しない欄（例えば、婚姻の届出がまだ受理されていないときの夫婦の財産の欄）は、その欄の条の答えを出さないだけで、「この組み合わせはありません」にはしません。成り立たない組（婚姻の届出をしていないのに受理された、など）は「この組み合わせはありません」と根拠の条とともに出します。「この組み合わせはありません」になるのは、7と8、8と10、1と10、6と10、15と17と18、8と21、21と24、21と25、21と27、21と29、21と31、11と21、5と8と21の欄の組です。離婚の欄が「していない」以外のときは、離婚の条（第763条〜第771条）の答えだけを出し、夫婦の氏と財産の条（第750条〜第762条）は、婚姻の届出が受理され、無効でなく、離婚していないときだけ出します。

判定しないもの：「婚姻をする意思」「詐欺又は強迫」「日常の家事」「不貞な行為」「悪意で遺棄」「婚姻を継続し難い重大な事由」「婚姻の継続を相当と認める」の7つに当たるかは判定しません。裁判所などが決める評価なので、欄で選んだとおりに当たるものとして条を当てます。「その親族」の範囲、親等、三箇月や五年の数え方（初日を入れるか）も計算しません。

条文だけを読んでいます。判例は載せません。別の法律（戸籍法、家事事件手続法、人事訴訟法、法務省令）も読んでいません。第740条・第765条第1項の「その他の法令の規定」も読んでいません。婚姻費用の額、財産の分与の額、親権者の定めの中身（第819条）は出しません。

入っていないもの：下の載せなかったものをご覧ください。相続は相続のページ、意思表示の取消しは意思表示のページで引けます。制限行為能力者（成年被後見人など）は、制限行為能力者の本で扱います（公開前です）。

第766条第3項・第4項、第766条の2、第766条の3は読んでいません（法務省令の額に行くため）。

民法のどこまでをルールにしたか（全条文の地図）

本則の全条文を1マスずつ並べました。 はプログラムのルールの中で使っている条、 は使っていない条です。マスを押すと原文が出ます。第766条は第1項・第2項だけを出します。

アプリの約束事（民法の条文にないもの）

判定のためにこのアプリが決めたことで、条文そのものではありません。論理の木では アプリの約束事 の印が付きます。

  • 条の要件に当たらないときは、欠けた要件が分かる起きた事実の文だけを出し、反対の結論は出さない
載せなかったものと、条文だけで決まらなかった点

載せなかったもの（理由）：

  • 判例：条文だけを読むアプリのため
  • 第725条〜第730条の親族の範囲：依頼の範囲の外のため。第735条・第736条に出る第728条・第729条は番号だけ
  • 第766条第3項・第4項、第766条の2、第766条の3：法務省令の額に行くため
  • 第772条以降の親子：婚姻と離婚の節の外のため
  • 第818条以降の親権：第765条の親権者の定めの有無だけを入力にし、第819条の中身は読まないため
  • 第877条以降の扶養：婚姻と離婚の節の外のため
  • 第897条の中身：第769条に番号が出るだけで、相続のページの範囲のため
  • 戸籍の手続：別の法律のため

条文だけで決まらなかった点（21点）：

  • （a）742条第2号ただし書の「方式を欠くだけ」は、受理された場合かが同号に書いていない（740条は受理の前の決まり） → 婚姻の届出が「受理された」ときだけ同号ただし書を当て、受理の前は740条を当てる。これは読みです
  • （b）744条1項の「その親族」の範囲は同項に書いていない → 第725条を読まない範囲なので、欄で「当事者の親族」を選んだとおりに当てる。これは読みです
  • （c）745条で、不適齢者でない当事者や親族が適齢に達した後に請求できるか → 1項は請求者を限っていないので、できないと読み、2項の不適齢者だけを例外と答える。これは読みです
  • （d）747条2項・745条2項・767条2項の「三箇月」と768条2項の「五年」の数え方（初日を入れるか）は書いていない → 欄で選んだとおりに当てる。これは読みです
  • （e）764条の747条の準用で「婚姻」を「協議上の離婚」に読み替えるのは文字で書いていない → 読み替えて答える。これは読みです
  • （f）761条の「日常の家事」の範囲と、これを超えたときの効力は書いていない → 欄で「した」を選んだときだけ761条を当てる。これは読みです
  • （g）762条2項の推定を覆す方法は書いていない → 推定とだけ答える。これは読みです
  • （h）770条2項は第四号を挙げていない → 第四号のときに同項の棄却はないと答える。これは読みです
  • （i）756条・759条は登記をしたときの文を書いていない → 登記をしたなら対抗することができると答える。これは読みです
  • （j）744条1項に挙がっていない人が請求したときの扱いは書いていない → 請求することができないと答える。これは読みです
  • （k）747条1項は「詐欺又は強迫によって婚姻をした者」だけを挙げる → それ以外の人の請求は同項に当たらないと答える。これは読みです
  • （l）731条などに違反した婚姻の届出が受理されたときの効力は740条に書いていない → 受理された後は740条を当てず、744条・745条の取消しを当てる。これは読みです
  • （m）742条の「次に掲げる場合に限り」から、第1号にも第2号にも当たらなければ同条の無効ではないと読む → 742条の答えを出さない。これは読みです
  • （n）765条2項の「前項の規定に違反して受理された」に方式を欠く届出も入るか → 入ると読み、同じ答えを出す。これは読みです
  • （o）768条は協議が調ったときの財産の分与の中身を書いていない → 768条2項の答えを出さない。これは読みです
  • （p）749条・751条2項・771条の準用の読み替えは書いていない → 準用されるとだけ答え、読み替えた答えは出さない。これは読みです
  • （q）当事者の一方が死亡した後の離婚を、763条・770条1項は「できない」と書いていない → 離婚の定めは「夫婦」の離婚なので、離婚する夫婦がいないとして「この組み合わせはありません」にする。これは読みです
  • （r）742条で無効な婚姻の離婚を、763条・770条1項は「できない」と書いていない → 離婚の定めは「夫婦」の離婚なので、離婚する夫婦がいないとして「この組み合わせはありません」にする。これは読みです
  • （s）婚姻の障害がある婚姻の届出が受理され、誰も取消しを請求していないとき → 744条・745条・747条ごとに、請求できる人（ただし書・期間の限定を含む）を答える。これは読みです
  • （t）離婚をするときに、婚姻の条と夫婦の氏と財産の条も並べるかは条文に書いていない → 離婚の欄が「していない」以外なら第763条〜第771条だけを答え、第750条〜第762条は受理され・無効でなく・離婚していないときだけ答える（第752条はそのときいつも、第760条〜第762条は財産について別段の契約をしなかったときだけ）。これは読みです
  • （u）十八歳未満で婚姻の届出をして、まだ受理されていないのに「十八歳になった後」を選んだとき → 婚姻の時に十八歳未満だったとして、731条に違反し、740条で受理できないと答える。これは読みです
